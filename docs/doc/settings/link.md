# 联动设置

::: tip 版本提示
本文档对应 **v3** 的"设置 → 联动设置"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **课程联动** - 连接课程表数据源，让抽取与课程时间节奏保持一致。

## 课程联动

### 数据源
**功能说明**：选择课程或外部联动数据来源

| 选项 | 说明 |
|------|------|
| **关闭** | 不启用课程联动 |
| **CSES 课程表** | 使用 CSES 课程表文件（`cses_schedule.yml`） |
| **ClassIsland** | 通过 ClassIsland 应用获取课程信息 |

### 限制非上课时段操作
**功能说明**：课程数据源明确显示处于课间或非上课时段时，限制抽取和重置；关闭后不作限制

### 允许验证后继续
**功能说明**：仅在已启用非上课时段限制时生效

- 开启：通过已配置的安全验证可以临时继续抽取或重置
- 关闭：非上课时段直接阻止抽取/重置

### 下课隐藏悬浮窗
**功能说明**：课程结束时自动隐藏悬浮窗

## CSES 课程表

### 导入课程表
1. 点击 **"导入课程表"** 按钮
2. 选择 CSES 课程表文件
3. 导入后自动解析，可查看摘要

### 查看摘要
显示课程表摘要：共 N 节课，最早/最晚时间。

### 清除课程表
点击 **"清除课程表"** 移除已导入的课程表。

### 课程表格式校验
导入时会校验课程表格式：
- 文件不能为空
- 根节点必须是对象
- 必须有有效课程
- 每节课的开始时间必须早于结束时间
- 同一星期的课程时间不能重叠

::: tip
CSES 课程表文件位于 `data/CSES/cses_schedule.yml`（桌面端）。
:::

## 课前课后

### 课前重置
**功能说明**：上课前自动重置临时抽取记录

### 课前重置时间
**功能说明**：距离上课多少秒内执行课前重置

### 课前解禁时间
**功能说明**：上课前多少秒提前解除课间禁用

### 课后禁用延迟
**功能说明**：课程结束后延迟多少秒禁用相关抽取入口

## 科目历史记录

### 科目历史记录过滤
**功能说明**：计算权重时只使用当前科目的历史记录

### 课间归属
**功能说明**：选择课间时段的历史记录归属方式

| 选项 | 说明 |
|------|------|
| **上节课** | 课间抽取记录归入上节课 |
| **下节课** | 课间抽取记录归入下节课 |
| **课间** | 课间抽取记录单独标记为"课间" |

::: tip
开启科目历史过滤后，公平抽取的权重计算会按课程区分，让每节课的抽取更均衡。
:::

## 注意事项

- 只有确认的课程休息时间才限制本地抽取/重置或隐藏悬浮窗；数据缺失、连接断开或未知状态时允许正常操作
- ClassIsland 连接失败、计时器未运行、课程表未启用或未加载时，会显示对应的错误提示
