# 历史记录

::: tip 版本提示
本文档对应 **v3** 的"设置 → 历史记录"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **记录可查** - 查看与管理点名和抽奖历史，持续优化抽取策略。

## 历史记录页面

历史记录包含两个标签页：
- **点名历史**：查看点名抽取记录
- **抽奖历史**：查看抽奖抽取记录

## 点名历史

### 选择名单
**功能说明**：选择要查看的成员名单

### 查看模式
**功能说明**：选择历史记录的查看模式

| 模式 | 说明 |
|------|------|
| **全部记录** | 汇总显示该名单所有成员的统计信息 |
| **按时间查看** | 按时间顺序查看每次抽取的记录 |

### 统计信息（全部记录模式）
- **名称**：成员名称
- **点名次数**：该成员被抽中总次数
- **序号/编号**：成员编号
- **性别**：成员性别
- **分组**：成员分组
- **点名模式**：抽取方式（随机抽取/公平抽取）
- **点名数量**：每次抽取的人数

### 按时间查看
- 按时间列出每次抽取记录
- 显示抽取时间、抽取方式、点名数量、课程等信息

## 抽奖历史

### 选择奖池
**功能说明**：选择要查看的抽奖奖池

### 查看模式
- **全部记录**：汇总显示该奖池所有奖品的统计信息
- **按时间查看**：按时间顺序查看每次抽取的记录

### 统计信息（全部记录模式）
- **名称**：奖品名称
- **中奖次数**：该奖品被抽中总次数
- **序号**：奖品编号
- **抽取数量**：每次抽取的奖品数

## 课程与课间

### 课程标识
历史记录显示每次抽取所属的**课程**（科目）。

### 课间归属
当联动设置启用后，课间时段的抽取记录会按配置归入：
- **上节课**
- **下节课**
- **课间**

::: tip
科目历史记录过滤开启后，公平抽取只使用当前科目的历史记录计算权重。
:::

## 刷新

点击 **"刷新"** 重新加载历史记录数据。
