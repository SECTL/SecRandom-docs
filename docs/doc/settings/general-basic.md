# 基本设置（通用）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 通用 → 基本"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

基本设置管理软件的核心行为，包括启动行为、窗口行为、语言与崩溃恢复。

## 行为

### 开机自启
**功能说明**：设置软件是否随系统启动自动运行

**适用场景**：
- 大屏设备等需要开机自启的场景
- 希望软件始终在后台运行的用户

**操作方式**：点击开关按钮即可开启或关闭

**注意事项**：
- 跨平台（Windows/Linux/macOS）使用系统级机制实现
- 如果杀毒软件出现报毒，可直接放行操作或关闭杀毒软件后再设置开机自启

### 启动显示主窗口
**功能说明**：设置软件启动时是否自动显示主窗口

**适用场景**：
- 开启：启动后立即显示主界面，方便快速操作
- 关闭：启动后在后台运行

**操作方式**：点击开关按钮即可开启或关闭

### 自动保存窗口大小
**功能说明**：是否自动保存窗口大小和位置

**适用场景**：
- 开启：下次启动软件时，主窗口与设置窗口会恢复到上次关闭时的大小和位置（独立记忆）
- 关闭：每次启动软件都使用默认窗口大小和位置

**操作方式**：点击开关按钮即可开启或关闭

### 主窗口置顶模式
**功能说明**：选择主窗口是否保持在其他窗口上方

**可选选项**：
- **关闭置顶**：不置顶
- **置顶**：普通置顶
- **UIAccess 置顶**（仅 Windows）：在重启时请求管理员权限以获取系统 UIAccess 令牌，可穿透多数全屏窗口

**操作方式**：在下拉框中选择

**注意事项**：
- UIAccess 模式取消或失败时，本次启动回退为普通置顶
- 非 Windows 平台仅提供"置顶/不置顶"选项

### 后台驻留
**功能说明**：关闭所有窗口后是否仍在后台常驻

**适用场景**：
- 开启：关闭主窗口后，软件仍在后台运行，可以通过托盘图标或其他方式重新打开
- 关闭：关闭主窗口后，软件完全退出

**操作方式**：点击开关按钮即可开启或关闭

### URL 协议注册 & IPC 服务
**功能说明**：注册自定义 URL 协议（`secrandom://`），并启用 IPC 通信，支持链接启动与外部联动

**适用场景**：
- 需要从浏览器或其他应用通过链接启动软件
- 需要与其他应用进行数据交互
- 需要接收外部指令控制软件

**操作方式**：点击开关按钮即可开启或关闭

**使用示例**：
```
secrandom://roll_call/start  # 启动点名功能
secrandom://lottery/draw     # 启动抽奖功能
```

**注意事项**：
- 注册失败会显示错误提示
- 详细的协议与 IPC 文档见 [IPC & URL 协议](/doc/resources/ipc_url)

### 显示语言
**功能说明**：切换软件界面语言

**可选选项**：简体中文、English、日本語

**操作方式**：在下拉框中选择

**注意事项**：部分版本需要重启软件后生效

## 崩溃恢复

### 崩溃恢复
**功能说明**：选择程序崩溃后的恢复方式

**可选选项**：
- **关闭**：不启用崩溃恢复
- **仅自动重启**：崩溃后自动重启程序
- **显示恢复页**：崩溃后显示恢复页面（含报错信息）
- **显示恢复页并自动重启**：显示恢复页并自动重启

**适用场景**：
- 重要场景中希望程序崩溃后能快速恢复，避免影响进行中的活动
- 需要查看崩溃原因以便反馈问题

**注意事项**：
- 崩溃恢复的提示处理发生在单实例检测之前
- 正常重启会先释放单实例服务再重新启动
