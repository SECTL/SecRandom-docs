# 安全设置（通用）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 通用 → 安全"页面。设置项可能随版本调整，请以实际界面为准。
:::

> **保障你的配置安全**
>
> 通过灵活的安全配置，保护你的系统免受未授权访问，所有设置实时保存并自动生效。

安全设置用于保护敏感操作（设置修改、抽取、窗口控制等），支持密码、TOTP 动态口令与 U 盘绑定三种验证方式，并可组合使用。

## 安全开关

**启用安全保护**：启用后，已选的操作会在执行前要求验证

- 开启：选定的安全操作均需验证
- 关闭：安全操作无需验证

::: tip
安全验证始终通过统一的安全服务执行，不会绕过。
:::

## 验证方式

### 启用密码验证
**功能说明**：使用本地密码保护敏感操作

**操作方式**：
1. 开启"启用密码验证"
2. 点击 **"设置密码"** 按钮，输入密码（至少 6 位）
3. 保存后生效

**注意事项**：
- 密码至少需要 6 位，无额外字符类别限制
- 可随时 **"修改密码"** 或 **"移除密码"**

### 启用 TOTP 验证
**功能说明**：使用一次性验证码保护敏感操作（即 2FA 验证）

**操作方式**：
1. 开启"启用 TOTP 验证"
2. 点击 **"设置 TOTP"** 按钮，使用认证器应用（如 Google Authenticator、Microsoft Authenticator）扫描二维码或输入密钥
3. 输入认证器生成的 6 位验证码完成绑定

**注意事项**：
- 可随时 **"重置 TOTP"**
- 验证码为 6 位动态口令

### 绑定 U 盘
**功能说明**：仅在绑定设备存在时允许通过验证

**操作方式**：
1. 开启"启用 USB 绑定"
2. 插入要绑定的 U 盘
3. 点击 **"绑定 U 盘"** 按钮完成绑定

**注意事项**：
- 绑定盘内会保存专用安全令牌（`.SecRandom.safety.key`）
- 可绑定多个设备，在"已绑定设备"列表中查看（盘符、磁盘名称、设备标识符、连接状态）
- 可 **"解绑"** 或 **"解绑所选"** 设备
- 绑定记录只保存稳定的设备 ID 与令牌哈希，不保存盘符等易变信息

## 保护范围

### 敏感操作前验证
**功能说明**：修改安全、联动、名单等关键设置前要求验证

### 联动操作前验证
**功能说明**：外部联动触发抽取或页面切换前要求验证

### 窗口与应用操作
保护以下操作（可选）：
- **打开设置**：打开设置窗口时需要验证
- **允许只读预览设置**：进入设置验证时允许预览设置内容（验证前只读，验证后才可修改）
- **显隐主窗口**：显示/隐藏主窗口需要验证
- **显隐浮窗**：显示/隐藏悬浮窗需要验证
- **重启应用**：重启软件需要验证
- **退出应用**：退出软件需要验证

### 抽取操作
分别保护每一种抽取的开始和重置操作：
- **点名开始 / 点名重置**
- **闪抽开始 / 闪抽清空**
- **抽奖开始 / 抽奖重置**

## 验证方式组合

### 验证方式
选择需要使用的验证方式组合（密码、TOTP、U 盘）

### 全部已选验证方式均需验证
- **开启**：必须完成全部已选验证方式才能通过
- **关闭**：任一已选方式通过即可继续

::: tip
密码始终用于保护凭据本身；其他验证方式需先配置后才能选用。
:::

## 防篡改

### 设置文件防篡改校验
**功能说明**：开启后记录整份设置文件的指纹，启动时校验该文件是否被程序之外修改

**篡改处理方式**（校验发现被外部修改后要执行的操作）：

| 选项 | 说明 |
|------|------|
| **需要安全密码确认后继续** | 输入安全密码以接受当前设置文件，否则程序退出 |
| **自动恢复最近一次备份** | 自动从备份恢复设置文件，恢复前的文件会另存备份，完成后自动重启 |

**恢复数据来源**（自动恢复时依次尝试的备份来源）：
- **仅本地备份**
- **本地优先，缺失时使用云端备份**
- **云端优先，失败时使用本地备份**

**注意事项**：
- 云端备份需要已登录账号，且**只使用本机上传的备份**，不会使用其他设备的备份

## Sudo 模式

### 启用 Sudo 模式
**功能说明**：验证一次后在有效期内免重复验证，操作与设置窗口分别独立计时

- **开启**：有效期内受保护的操作不再要求验证
- **关闭**：每一次受保护操作都需要重新验证

### Sudo 有效时长
**功能说明**：验证通过后的免验证时长

**可选范围**：10–600 秒（默认 20 秒，步进 10 秒）

**操作范围**：抽取、重置、开关窗口、退出程序、快捷键与 IPC 指令

**设置窗口范围**：打开设置验证后，本窗口内的设置改动同样免验证，但**关闭窗口会立即失效**；关闭安全保护、取消验证方式、关闭防篡改校验或延长本时长等**放宽防护**的改动，始终需要重新输入安全密码

**不受影响的操作**：配置 TOTP、修改或移除密码、绑定 USB 设备始终需要重新验证

**注意事项**：
- 托盘菜单中的 **"退出 Sudo 模式"** 可立即结束免验证状态（仅在 Sudo 模式生效时显示）

## 安全设置建议

1. 启用安全开关增强系统安全性
2. 设置强密码并定期更换
3. 根据需要启用 U 盘/TOTP 验证作为双重保障
4. 对重要操作（如退出软件、打开设置、抽取）启用验证
