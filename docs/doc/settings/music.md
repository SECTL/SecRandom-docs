# 音乐库（个性化）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 个性化 → 音乐"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **抽取配乐** - 管理抽取背景音乐，让每次抽取都更有氛围。

## 本地音乐库

**功能说明**：导入的音乐会复制到应用数据目录，可供所有抽取场景选择

### 导入音乐
1. 点击 **"导入音乐"** 按钮
2. 选择音乐文件（支持 **MP3 / WAV / FLAC** 格式）
3. 文件将复制到应用数据目录的音乐库

### 音乐列表
音乐库列表显示：
- **曲目**：音乐文件名
- **格式**：文件格式
- **大小**：文件大小
- **操作**：试听 / 停止 / 删除

### 试听
点击 **"试听"** 播放所选曲目，点击 **"停止"** 停止播放。

### 删除音乐
点击 **"删除"** 移除曲目。

**注意事项**：
- 删除曲目后，全局和每个抽取记录中的对应音乐引用会一并清理
- 抽取设置中的"音乐"选项使用相同的音乐库 ID（无音乐/随机播放/指定曲目）

## 抽取中的音乐使用

在 **抽取设置** 或各抽取方式的附加设置中，可以为抽取配置音乐：
- **无音乐**：抽取时不播放音乐
- **随机播放**：从音乐库随机选择一首
- **指定曲目**：选择音乐库中的特定曲目

::: tip
抽取音乐与语音播报相互独立，可同时使用。
:::
