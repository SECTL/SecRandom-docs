# 备份设置（通用）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 通用 → 备份"页面。设置项可能随版本调整，请以实际界面为准。
:::

> **数据无忧** - 通过自动/手动备份与一键恢复，保护你的名单、历史与配置数据。

## 自动备份

### 自动备份
**功能说明**：是否启用自动备份

- 开启：按设定的间隔自动创建备份
- 关闭：不自动备份（仍可手动备份）

### 自动备份间隔
**功能说明**：设置自动备份间隔（天）

### 自动备份上限
**功能说明**：设置自动备份最多保留数量（个），0 为不限制

**注意事项**：超过上限时，最早的备份会被自动清理

## 备份内容

选择需要包含在备份文件中的数据：

| 内容 | 说明 |
|------|------|
| **配置文件** | 软件设置与配置文件（config） |
| **名单数据** | 点名/抽奖名单等数据（list） |
| **历史记录** | 抽取历史记录数据（history） |
| **抽取证明文件** | 可复现和核验抽取结果的证明文件（proofs） |
| **音频资源** | 音频资源文件（audio） |
| **CSES 联动** | CSES 相关联动数据（CSES） |
| **图片资源** | 成员/奖品图片资源（images） |
| **主题资源** | 已安装的主题资源（theme） |
| **运行日志** | 程序运行日志，可能包含敏感信息（logs） |

::: warning 注意
备份不会包含密码等安全信息。安全凭据存储在独立的加密凭据库中，不随备份导出。
:::

## 手动操作

### 立即备份
点击按钮立即创建一份全量备份。

### 查看备份文件
打开备份文件夹，查看备份文件列表（文件名、创建时间、大小）。

### 恢复备份
1. 在备份列表中选择要恢复的备份
2. 点击 **"恢复"**
3. 确认后执行恢复

**注意事项**：
- 恢复会覆盖当前对应数据
- 恢复前会自动创建一份当前数据快照
- 恢复完成后需要**重启应用**生效
- 只接受 SecRandom v3 生成的备份文件

### 删除备份
选择备份后点击 **"删除"**，此操作无法撤销。

## 备份占用

显示备份文件夹当前占用大小，便于评估存储使用情况。

## 云端备份

**功能说明**：登录 SECTL 账号后可将数据备份上传到云端并随时恢复；桌面端与移动端都提供该页签，未登录时显示登录引导。

| 设置 | 说明 |
|------|------|
| **账号状态** | 当前用于云同步的 SECTL 账号 |
| **云端空间** | 当前账号的云空间用量与本应用占用；可在浏览器中打开思拓创联云储存页面管理云端文件 |
| **云端备份内容** | 选择需要包含在备份文件中的数据（分项与本地备份一致） |
| **设备别名** | 用于区分不同设备的云端备份，会显示在云端文件名中；留空则使用本机名称 |
| **立即备份到云端** | 将所选数据打包上传到云端 |

### 云端自动备份
**功能说明**：按设定的间隔自动备份到云端

- **自动备份间隔**：云端自动备份间隔（天）
- **自动备份上限**：本设备在云端最多保留的备份数量（个），0 为不限制；超出后自动删除**本设备**最早的备份
- 云空间不足时，才会进一步删除整个账号最早的云端备份

### 云端备份管理
列出已上传的云端备份，可**下载恢复**或**删除**；恢复前会先校验下载到的内容。

::: warning 注意
- 云端备份需要登录 SECTL 账号
- 云端备份**不做客户端加密**：归档按原样上传，能登录该账号的设备都可以列出并恢复其中的备份；安全凭据（密码、TOTP、USB 绑定等）不会包含在备份中
- 由已被移除的加密功能上传的旧备份仍会显示，但标记为"旧版加密，无法恢复"，只能查看或删除
:::
