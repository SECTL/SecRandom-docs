# 名单管理

::: tip 版本提示
本文档对应 **v3** 的"设置 → 名单管理"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **高效管理** - 通过直观的名单管理界面，轻松创建、导入、导出和维护点名名单与抽奖奖池。

## 名单结构

v3 的名单管理包含四个子页面：

| 页面 | 说明 |
|------|------|
| **点名名单** | 管理多个学生名单 |
| **点名表格** | 以表格方式管理点名名单数据 |
| **抽奖名单** | 管理多个奖品奖池 |
| **抽奖表格** | 以表格方式管理抽奖奖池数据 |

---

## 一、点名名单

### 1. 当前名单

**当前名单**：选择要查看或导入的成员名单

- 点击下拉框切换当前名单
- 切换后，下方成员列表自动刷新为该名单的数据

### 2. 名单操作

- **新增名单**：创建新的点名名单
- **重命名**：重命名当前名单
- **删除名单**：删除当前名单（此操作不可撤销）

### 3. 成员管理

- **添加成员**：填写序号/编号或名称（至少一项），可选性别、分组、标签
- **删除成员**：删除选中的成员
- **刷新**：刷新成员列表

#### 添加成员的公平性提示
当名单中所有现有成员抽取次数都不为 0 时，新增成员后使用公平抽取可能会使新成员的抽中几率增大。软件会询问是否**删除该名单的历史记录**，清除后公平抽取效果更好。

### 4. 导入成员名单

**支持格式**：`.xlsx`、`.xls`、`.csv`（第一行作为列名）

**操作步骤**：
1. 点击 **"导入名单"** 按钮
2. 选择本地文件（Excel/CSV）
3. 设置**列映射**：
   - 序号/编号列、名称列（至少选择一项）
   - 性别列、分组列、标签列（可留空）
4. 在预览区域查看要导入的数据
5. 处理重复名称（保留重名导入 / 自动重命名）
6. 确认覆盖提示（若当前名单已有成员）
7. 点击 **"导入"** 完成

**注意事项**：
- 序号/编号和名称两项均为空的行不会导入
- 系统使用内部标识区分记录，重名不会导致数据混乱

### 5. 导出成员名单

1. 点击 **"导出名单"** 按钮
2. 选择保存路径和文件格式
3. 点击 **"保存"** 完成导出

## 二、抽奖名单（奖池）

### 1. 当前奖池

**当前奖池**：选择要查看或导入的抽奖奖池

### 2. 奖池操作

- **新增奖池**：创建新的奖池
- **重命名**：重命名当前奖池
- **删除奖池**：删除当前奖池（此操作不可撤销）

### 3. 奖品管理

- **添加奖品**：填写 ID/编号或奖品名称（至少一项），可选权重、数量、标签
  - 权重和数量必须是大于 0 的有效数字
- **删除奖品**：删除选中的奖品

### 4. 导入抽奖奖池

**支持格式**：`.xlsx`、`.xls`、`.csv`（第一行作为列名）

**操作步骤**：
1. 点击 **"导入奖池"** 按钮
2. 选择本地文件（Excel/CSV）
3. 设置**列映射**：
   - ID/编号列、奖品名称列（至少选择一项）
   - 权重列、数量列、标签列（可留空）
4. 预览、处理重复、确认覆盖后导入

### 5. 导出抽奖奖池

与点名名单导出类似，选择保存路径和格式后导出。

## 三、名单传输（v3 新增）

v3 支持通过二维码、会话码等方式在设备间传输名单：

### 导出到其他设备
- **二维码导出**：将名单/设置编码为二维码，用另一台设备扫描导入
- **会话码导出**：生成会话码，在其他设备上输入后传输
- **快速/离线导出**：通过本地文件快速导出

### 从其他设备导入
- **摄像头扫码**：使用摄像头扫描另一台设备显示的二维码（支持选择摄像头）
- **会话码导入**：输入对方设备的会话码
- **文件导入**：选择对方导出的文件

**注意事项**：
- 名单传输有统一的传输大小限制
- 摄像头扫码支持选择平台摄像头（Windows/Linux/macOS/Android 均可使用）
- 支持云同步链接与复制按钮
