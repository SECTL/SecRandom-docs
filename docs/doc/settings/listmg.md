# 名单管理

::: tip 版本提示
本文档对应 **v3** 的"设置 → 名单管理"页面。设置项可能随版本调整，请以实际界面为准。
:::

> **高效管理** - 通过直观的名单管理界面，轻松创建、导入、导出和维护点名名单与抽奖奖池。

## 名单结构

v3 的名单管理包含两个页面，结构一致，都是"先选名单、再在表格里维护条目"：

| 页面 | 说明 |
|------|------|
| **成员名单** | 管理多个学生名单，表格中维护序号/编号、名称、性别、分组与标签 |
| **抽奖名单** | 管理多个奖品奖池，表格中维护 ID/编号、奖品名称、权重、数量与标签 |

---

## 一、成员名单

### 1. 当前名单

**当前名单**：选择要查看或导入的成员名单

- 点击下拉框切换当前名单
- 切换后，下方成员表格自动刷新为该名单的数据

### 2. 名单操作

- **新增名单**：创建新的点名名单
- **重命名**：重命名当前名单
- **删除名单**：删除当前名单（此操作不可撤销）

### 3. 成员管理

- **添加成员**：填写序号/编号或名称（至少一项），可选性别、分组、标签
- **编辑成员**：修改成员的各项字段；取消勾选 **"存在"** 后，该成员不再作为候选项参与抽取
- **删除成员**：删除选中的成员
- **刷新**：刷新成员列表

#### 添加成员的公平性提示
当名单中所有现有成员抽取次数都不为 0 时，新增成员后使用公平抽取可能会使新成员的抽中几率增大。软件会询问是否**删除该名单的历史记录**，清除后公平抽取效果更好。

### 4. 导入成员名单

点击 **"导入名单"** 按钮后，先在抽屉顶部的 **"导入方式"** 中选择一种方式：

| 导入方式 | 数据来源 | 是否需要联网 |
|----------|----------|--------------|
| **从 Excel/CSV 文件导入** | 本地的表格文件 | 不需要 |
| **扫码快速导入** | 另一台设备展示的二维码 | 两台设备都要联网 |
| **无网扫码导入** | 另一台设备展示的多帧二维码 | 不需要 |
| **会话码导入** | 另一台设备给出的 12 位会话码 | 需要联网 |

无论使用哪一种方式，都会先进入预览，确认后点击 **"导入"** 写入当前名单。

#### 4.1 从 Excel/CSV 文件导入

**支持格式**：`.xlsx`、`.xls`、`.csv`（导入区域可自行选择）

**操作步骤**：
1. 点击 **"选择 Excel/CSV 文件"** 并选中文件
2. 在 **"导入区域"** 中确认工作表、表头行与数据行范围
3. 设置**列映射**：
   - 序号/编号列、名称列（至少选择一项）
   - 性别列、分组列、标签列（可留空）
4. 在预览区域查看要导入的数据
5. 处理重复名称（保留重名导入 / 自动重命名）
6. 确认覆盖提示（若当前名单已有成员）
7. 点击 **"导入"** 完成

**导入区域**说明：

| 设置 | 说明 |
|------|------|
| **工作表** | 文件中有多个工作表时出现；切换后会按该工作表重新读取文件。CSV 与只含一个工作表的文件不显示该项 |
| **表头行** | 默认按序号/编号、名称、性别、分组、标签等关键字在前 10 行内自动识别；识别不出来时按第一行处理并给出提示，可手动指定 |
| **无表头** | 选择"无表头（用 A、B、C 作为列名）"后，列名退化为 Excel 的列字母 |
| **数据行范围** | 用**表格的原始行号**（从 1 开始，与在 Excel 中看到的行号一致）指定起始行与结束行，区域以外的内容不会被导入 |
| **原始行预览** | 显示表头行附近的 5 行，**点击任意一行即可将其设为表头行**；更靠后的行请在"表头行"下拉框中选择 |

**注意事项**：
- 序号/编号和名称两项均为空的行不会导入
- 区域内没有可导入的数据行时会提示"当前导入区域内没有可导入的数据行，请调整导入区域"
- 系统使用内部标识区分记录，重名不会导致数据混乱

::: tip 表格开头有标题行或空行怎么办？
不必再手工裁剪文件：把 **表头行** 指到真正的标题行、把 **数据行范围** 收到数据部分即可，表格尾部的合计行与空行也会一并排除。
:::

#### 4.2 扫码快速导入

需要两台设备都能访问网络，二维码只有一帧：

1. 在另一台设备上选择 **"扫码快速导出至其它设备"**
2. 本机选择"扫码快速导入"，摄像头会自动打开，可先在下拉框中选择摄像头
3. 用摄像头对准另一台设备上的二维码
4. 识别成功后自动取回名单，预览确认后点击 **"导入"**

#### 4.3 无网扫码导入

完全不依赖网络：另一台设备把整份名单拆成多帧二维码轮播，本机连续扫码拼回完整数据。

1. 在另一台设备上选择 **"无网导出至其它设备"**
2. 本机选择"无网扫码导入"，用摄像头对准二维码并保持画面稳定
3. 面板会显示传输进度、传输速度、已传输/总大小、新帧/重复/无效、会话与已用时间
4. 进度完成后预览确认并点击 **"导入"**

::: warning 摄像头相关的提示
- 未获得摄像头权限、或摄像头启动失败时，界面会给出对应提示，可改用文件导入或会话码导入
- 无网扫码导入对画面质量要求更高，尽量让二维码充满画面并保持稳定
:::

#### 4.4 会话码导入

需要联网：

1. 在另一台设备上选择 **"会话码导出至其它设备"**，得到一段 12 位会话码
2. 在本机输入会话码（12 位字母或数字），输入满 12 位后自动验证
3. 验证成功后预览确认并点击 **"导入"**

输入过程中修改会话码会取消上一次验证；会话码无效或已过期时会给出提示。

#### 4.5 导入时的共同处理

- 预览区域展示前 3 行数据，用于确认列映射是否正确
- 发现重复名称时，可选择 **"保留重名导入"**（系统用内部标识区分记录）、**"自动重命名"**，或 **"返回修改"**
- 当前名单已有成员时，会先提示本次导入将覆盖当前名单内容

### 5. 导出成员名单

点击 **"导出名单"** 按钮后，同样先选择 **导出方式**：

| 导出方式 | 说明 |
|----------|------|
| **导出为文件** | 导出为 `.xlsx` 或 `.csv` 文件 |
| **扫码快速导出至其它设备** | 生成配对二维码，其它设备联网扫码后取回名单 |
| **无网导出至其它设备** | 生成多帧轮播二维码，对方无需联网即可扫码接收 |
| **会话码导出至其它设备** | 生成 12 位会话码，并提供复制按钮 |

**注意事项**：
- 扫码快速导出与会话码导出期间会显示同步门户地址（`secrandom-sync.sectl.cn`），在其它设备的浏览器打开该地址也能接收名单文件，无需安装软件
- 导出过程中可点击 **"停止导出"** 提前结束传输

## 二、抽奖名单（奖池）

### 1. 当前奖池

**当前奖池**：选择要查看或导入的抽奖奖池

### 2. 奖池操作

- **新增奖池**：创建新的奖池
- **重命名**：重命名当前奖池
- **删除奖池**：删除当前奖池（此操作不可撤销）

### 3. 奖品管理

- **添加奖品**：填写 ID/编号或奖品名称（至少一项），可选权重、数量、标签
  - 权重和数量必须是大于 0 的有效数字
- **编辑奖品**：修改奖品的各项字段；取消勾选 **"存在"** 后，该奖品不再作为候选项参与抽取
- **删除奖品**：删除选中的奖品

### 4. 导入抽奖奖池

点击 **"导入奖池"** 按钮后，导入方式与成员名单完全一致：

- **从 Excel/CSV 文件导入**（支持 `.xlsx`、`.xls`、`.csv`，同样可以选择工作表、表头行与数据行范围）
- **扫码快速导入**
- **无网扫码导入**
- **会话码导入**

差别只在**列映射**：

- ID/编号列、奖品名称列（至少选择一项）
- 权重列、数量列、标签列（可留空）

预览、重复处理与覆盖确认的流程与成员名单相同。

### 5. 导出抽奖奖池

与成员名单导出类似，同样提供**导出为文件**（`.xlsx`/`.csv`）、**扫码快速导出**、**无网导出**与**会话码导出**四种方式。

## 三、跨设备传输（v3 新增）

名单与设置都提供"本机 ↔ 其它设备"的传输能力，**文件 / 扫码快速 / 无网扫码 / 会话码**这四种方式在名单导入、名单导出，以及设置页"更多选项"里的导出/导入设置中是通用的：

| 方式 | 特点 |
|------|------|
| **文件** | 最通用，通过导出的文件手工传递；名单支持 `.xlsx`/`.csv` |
| **扫码快速** | 生成一个配对二维码，对方扫码后从同步服务取回；速度快，需要联网 |
| **无网扫码** | 数据被编码进多帧二维码轮播，完全离线可用；数据量大时耗时更长 |
| **会话码** | 一段 12 位会话码，口头或文字告知对方即可；需要联网 |

**注意事项**：
- 传输有大小上限：扫码快速与会话码经由同步服务的载荷上限为 **1 MiB**，无网二维码为 **300 KiB**
- 名单在导出端**先在本机加密**再上传：扫码快速把解密密钥放进二维码，会话码则由会话码本身派生密钥，服务端只保存口令哈希
- 摄像头扫码支持选择平台摄像头（Windows/Linux/macOS/Android 均可使用）
- 传输只包含名单、设置等内容，安全凭据（密码、TOTP、USB 绑定等）不会随传输导出
