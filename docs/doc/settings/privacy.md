# 隐私设置（通用）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 通用 → 隐私"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **隐私可控** - 了解并管理软件的网络数据上报，所有选项默认开启，可随时修改。

## Sentry 遥测

**启用 Sentry 遥测**：开启后上传崩溃、日志、追踪和性能分析数据，用于诊断问题和改进稳定性

**注意事项**：
- 该选项**不控制**在线状态统计
- 关闭后，后续遥测网络请求将停止
- 首次启动时会在引导流程中展示隐私政策说明

## 在线状态统计

**在线状态**：选择在线状态的报告方式

| 选项 | 说明 |
|------|------|
| **正常上报** | 参与在线人数统计，并包含由公网 IP 推导的粗略位置信息 |
| **匿名上报** | 仅计入在线人数，不上传 IP 或地区信息 |
| **停止上报** | 不参与在线状态统计 |

**注意事项**：
- 只有在对应选项开启后，应用才会进行相应的网络请求
- 关闭选项后，后续请求将停止

## 隐私政策要点

- **本地数据**：名单、奖品、历史和设置默认保存在本地；请确保导入的数据来源合法、准确且经过授权
- **选择与变更**：以上隐私选项默认开启，可在本页或引导流程中随时修改
- **网络请求**：只有在对应选项开启后，应用才会进行相应的遥测或在线状态网络请求
- **更新与终止**：隐私政策发生实质变更时会提高政策版本并要求重新确认
