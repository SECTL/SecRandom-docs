> ::lucide:puzzle:: **插件管理**
>
> 通过已安装与市场两个视图管理桌面端插件，所有安装、启用或卸载操作在重启应用后生效。

::: info 桌面端功能
插件是桌面端功能，移动端不加载动态插件。设置 → **插件**页面仅在桌面端显示。
:::

## ::lucide:box:: 已安装

**插件列表**：显示已安装插件，包括名称、版本、作者与加载状态（已加载 / 已禁用 / 加载失败 / 已发现）。

**搜索**：按插件名称、id 或作者过滤列表。

**详情面板**：选中插件后显示其图标、元信息、状态与自述（README）。加载失败的插件会展示错误信息，可点击「打开文件夹」检查插件目录。

### 启用 / 禁用

开启或关闭某个插件的启用开关，操作结果在**重启应用**后生效。

### 导入本地包

点击「导入」选择一个 `.srpx` 插件包：

- 包会先经过清单与入口程序集校验，再暂存到 `data/cache/plugin-packages`。
- 重启应用后完成安装；同 id 的包视为更新，会整目录替换。

### 卸载

选中插件后点击「卸载」，确认后：

- 插件目录在**下次启动**时被移除。
- 插件的配置目录（`data/config/plugins/<id>`）**保留**，便于以后重新安装时恢复配置。
- 卸载操作在重启应用后生效。

## ::lucide:store:: 市场

市场标签从官方索引（[SECTL/SecRandom-PluginIndex](https://github.com/SECTL/SecRandom-PluginIndex)）加载可安装的插件，每个条目显示名称、作者、版本与状态：

- **可安装 / 已安装 / 有更新**：点击「安装」或「更新」，确认依赖后开始安装，重启应用生效。
- **不兼容**：插件 `apiVersion` 主版本低于当前应用，或要求的宿主版本过高，无法安装。

::: tip 安全机制
市场索引经 Ed25519 签名校验，每个插件包在安装前都会校验 SHA-256，并会按依赖关系拓扑排序解析。但仍请注意，插件与应用同进程运行，只安装可信来源的插件。
:::
