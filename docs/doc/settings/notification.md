# 提醒设置（通知）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 提醒设置"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **即时反馈** - 配置抽取完成后的通知提醒，让结果清晰可感知。

## 提醒设置页面

v3 的提醒设置包含以下子页面：

| 页面 | 说明 |
|------|------|
| **语音与音乐** | 语音播报引擎、音色、音量与抽取音乐（见[语音与音乐](/doc/settings/voice)） |
| **默认提醒设置** | 全局默认通知配置 |
| **点名提醒设置** | 点名完成后的通知配置 |
| **闪抽提醒设置** | 闪抽完成后的通知配置 |
| **抽奖提醒设置** | 抽奖完成后的通知配置 |

各通知页面共享相同的配置结构，并支持 **"启用覆盖"**：开启后，该抽取方式使用自身配置覆盖默认通知设置。

---

## 通知服务

### 通知服务类型
**功能说明**：选择通知的投递方式

| 选项 | 说明 |
|------|------|
| **SecRandom 内置通知** | 使用内置通知浮窗显示结果 |
| **ClassIsland** | 通过 ClassIsland 通知（需安装 SecRandom4Ci 插件） |
| **同时使用** | 同时使用内置通知与 ClassIsland |

### 通知服务失败回退
**功能说明**：当前选择通知服务发送失败后，自动回退到内置通知服务

- 开启：所选外部通知服务无法投递时，使用 SecRandom 内置通知服务继续显示
- 关闭：外部服务失败时不显示通知

### 通知显示器
**功能说明**：指定通知窗口显示在哪个显示器；不指定时使用主显示器

## 默认通知设置

### 启用通知
**功能说明**：抽取完成后显示通知结果

### 通知动画
**功能说明**：显示通知时播放进入和退出动画

### 通知位置
**功能说明**：选择通知浮窗显示位置

可选：左上、顶部、右上、左侧、中心、右侧、左下、底部、右下

### 通知偏移
**功能说明**：设置通知浮窗相对默认位置的水平和垂直偏移

### 通知不透明度
**功能说明**：设置通知浮窗的不透明度

### 通知显示时长
**功能说明**：设置通知服务显示结果的秒数

### 超过阈值时使用主窗口
**功能说明**：抽取数量超过阈值时不显示浮窗通知，仅在主窗口显示结果

### 通知阈值
**功能说明**：超过此数量后使用主窗口显示结果

---

## 内置通知浮窗

### 浮窗显示器
**功能说明**：指定内置通知浮窗显示在哪个显示器；不指定时使用主显示器

### 浮窗位置
**功能说明**：选择内置通知浮窗的显示位置

### 浮窗偏移
**功能说明**：设置内置通知浮窗相对默认位置的水平和垂直偏移

### 浮窗不透明度
**功能说明**：设置内置通知浮窗的不透明度

### 浮窗关闭时间
**功能说明**：内置通知浮窗自动关闭前保留的秒数

## 各抽取方式的通知

点名/闪抽/抽奖各自独立配置，可覆盖默认设置：

| 设置 | 点名 | 闪抽 | 抽奖 |
|------|------|------|------|
| 启用通知 | ✓ | ✓ | ✓ |
| 通知动画 | ✓ | ✓ | ✓ |
| 通知位置 | ✓ | ✓ | ✓ |
| 通知偏移 | ✓ | ✓ | ✓ |
| 通知不透明度 | ✓ | ✓ | ✓ |
| 通知显示时长 | ✓ | ✓ | ✓ |
| 超过阈值时使用主窗口 | ✓ | ✓ | ✓ |
| 通知阈值 | ✓ | ✓ | ✓ |

::: tip
各抽取方式的通知阈值含义不同：点名/闪抽为"抽取人数"，抽奖为"抽取奖品数"。
:::
