# 语音与音乐（提醒设置）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 提醒设置 → 语音与音乐"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **有声反馈** - 配置语音播报引擎、音色、音量与播报内容，让抽取结果即时可听。

## 语音播报

### 启用语音播报
**功能说明**：作为所有抽取语音播报的总开关；各抽取设置可单独控制是否播报

- 开启：抽取完成后播报结果
- 关闭：不播报

### 语音引擎
**功能说明**：选择用于播报的语音引擎

| 选项 | 说明 |
|------|------|
| **系统语音** | 使用操作系统内置语音合成 |
| **Edge TTS** | 使用微软 Edge TTS 在线语音合成（音色更丰富） |

### 音色
**功能说明**：根据当前语音引擎显示可用音色

- 系统语音：显示系统可用音色
- Edge TTS：使用 Edge TTS 的 voice 名称（如 `zh-CN-XiaoxiaoNeural`）

### 刷新音色
点击 **"刷新音色"** 刷新可用音色列表（联网时从服务获取）。

### 试听
点击 **"试听"** 按当前设置播报一条测试语音（"这是一条语音播报测试"）。

## 音量与语速

### 语音音量
**功能说明**：设置播报音量

### 语速
**功能说明**：设置播报速度百分比

## 系统音量控制

### 启用系统音量控制
**功能说明**：播报前自动调整系统音量

- 开启：播报时自动将系统音量调整到设定值
- 关闭：使用当前系统音量

### 系统音量大小
**功能说明**：设置语音播报时使用的系统音量

## 播报内容

### 播报编号
**功能说明**：结果中包含编号

### 播报名称
**功能说明**：结果中包含名称

## 播放行为

### 等待播报完成
**功能说明**：等待当前语音播报完成后再允许下一次抽取

- 开启：播报期间不能开始下一次抽取
- 关闭：可随时开始下一次抽取（播报可能被中断）

---

## 抽取音乐

抽取背景音乐在 **音乐库**（设置 → 个性化 → 音乐）中管理，在抽取设置或各抽取方式的附加设置中选择使用方式：

- **无音乐**：抽取时不播放音乐
- **随机播放**：从音乐库随机选择一首
- **指定曲目**：选择音乐库中的特定曲目

::: tip
抽取音乐与语音播报相互独立，可同时使用。
:::
