# 悬浮窗设置（个性化）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 个性化 → 浮窗"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **快捷抽取** - 通过悬浮窗随时发起点名、闪抽与抽奖，课堂节奏不断。

## 窗口显示

### 启动时显示悬浮窗
**功能说明**：控制程序启动后是否自动打开悬浮窗

### 悬浮窗不透明度
**功能说明**：设置悬浮窗的不透明度（同时应用到主悬浮窗和闪抽浮窗）

### 悬浮窗置顶模式
**功能说明**：选择悬浮窗是否保持在其他窗口上方

| 选项 | 说明 |
|------|------|
| **不置顶** | 不保持置顶 |
| **置顶** | 普通置顶 |
| **UIAccess 置顶**（仅 Windows） | 在重启时请求管理员权限，取消或失败时本次启动使用普通置顶 |

## 悬浮窗控件

### 悬浮窗控件（入口）
**功能说明**：选择主悬浮窗中显示的功能入口

- **点名**：显示点名入口
- **闪抽**：显示快速抽取入口
- **抽奖**：显示抽奖入口

### 控件排列
**功能说明**：选择悬浮窗控件的排列方式

- **矩形**：双列网格
- **纵向**：单列排列
- **横向**：单行排列

### 控件显示样式
**功能说明**：选择悬浮窗控件显示图标、文字或二者同时显示

- **图标和文字**
- **仅图标**
- **仅文字**

### 控件尺寸
**功能说明**：调整每个正方形控件的边长，图标和文字会同步缩放

可选：极小、很小、小、中、大、很大、特大

## 移动与贴边

### 可拖动
**功能说明**：关闭后主悬浮窗和收纳手柄都不能拖动

### 贴边功能
**功能说明**：拖动松开后自动吸附到当前屏幕最近的左侧或右侧边缘

### 自动收纳延迟
**功能说明**：贴边后等待指定秒数再收纳；设为 0 时保持展开

### 无焦点模式
**功能说明**：点击悬浮窗时尽量不抢占当前窗口焦点

### 长按判定时间
**功能说明**：触发长按操作需要持续的毫秒数

### 前台窗口隐藏悬浮窗
**功能说明**：当前前台窗口标题或进程名命中规则时自动隐藏悬浮窗

- **前台窗口标题**：标题包含匹配文本时隐藏（使用英文分号 `;` 分隔多个规则）
- **前台进程名**：命中进程名时隐藏，例如 `WeChat.exe`（使用英文分号 `;` 分隔）
