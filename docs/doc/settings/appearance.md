# 外观设置（个性化）

::: tip 版本提示
本文档对应 **v3** 的"设置 → 个性化 → 外观"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **个性化外观** - 定制主题、字体与主题颜色，让 SecRandom 符合你的审美。

## 主题

### 主题模式
**功能说明**：选择软件界面主题样式

| 选项 | 说明 |
|------|------|
| **浅色** | 使用浅色主题，适合白天使用 |
| **深色** | 使用深色主题，适合夜间使用 |
| **跟随系统** | 自动根据系统主题切换 |

### 主题颜色
**功能说明**：设置软件界面主题色彩

| 选项 | 说明 |
|------|------|
| **跟随系统** | 使用系统强调色 |
| **自定义** | 选择自定义主题色 |

**注意事项**：主题色应用于按钮、进度条、选中状态等界面元素

## 字体

### 字体家族
**功能说明**：设置软件界面显示字体家族

- 默认字体为 **MiSans**（内置）
- 可选择系统中其他可用字体

### 字体粗细
**功能说明**：设置软件界面字体粗细

可选：极细、特细、细体、常规、中等、半粗、粗体、特粗、极粗

## 字体预览

设置页提供实时字体预览，包含：
- 中文样例：树梢树枝树根根 亲山亲水有亲人
- 分组样例：第一分组 张三 第二分组 李四 第三分组 王五 第四分组 赵六
- 英文样例：the quick brown fox jumps over a lazy dog
- 数字与符号样例：点名 闪抽 抽奖 人脸抽 1234567890 +-*/

::: tip
调整字体与粗细后，预览区域即时更新，方便对比显示效果。
:::
