# 抽取设置

::: tip 版本提示
本文档对应 **v3** 的"设置 → 抽取设置"页面。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **精准抽取** - 配置抽取模式、显示效果、动画与提示语，让每次抽取符合你的预期。

## 抽取设置页面

v3 的抽取设置包含以下子页面：

| 页面 | 说明 |
|------|------|
| **默认抽取设置** | 全局默认抽取行为 |
| **点名抽取设置** | 点名页的抽取配置 |
| **闪抽抽取设置** | 闪抽（悬浮窗快速抽取）的配置 |
| **抽奖抽取设置** | 抽奖页的抽取配置 |
| **人脸抽取设置** | 人脸抽取模式的配置 |

各抽取页面共享相同的设置项结构，并支持 **"启用覆盖"**：开启后，该抽取方式使用自身配置覆盖默认设置。

## 抽取设置

### 抽取模式
**功能说明**：控制重复抽取记录的处理方式

| 选项 | 说明 |
|------|------|
| **允许重复** | 每次抽取均从完整候选池抽取，可重复抽中 |
| **不重复** | 已抽中成员在清除记录前不再进入候选池 |
| **半重复** | 抽中次数达到阈值后不再进入候选池 |

### 半重复阈值
**功能说明**：抽中次数达到该值后不会再次进入候选池（仅半重复模式）

### 清除记录
**功能说明**：控制抽取记录何时清除

| 选项 | 说明 |
|------|------|
| **重启后清除** | 临时抽取记录在重启后清除 |
| **手动清除** | 仅通过手动重置清除 |

::: warning 注意
清除记录只控制临时抽取记录，不会清除持久化的历史记录。
:::

### 抽取方式
**功能说明**：设置使用随机抽取或公平抽取

| 选项 | 说明 |
|------|------|
| **随机抽取** | 纯随机抽取 |
| **公平抽取** | 基于历史权重动态调整，降低重复与分布失衡 |

### 默认抽取名单 / 默认抽奖名单
- **默认抽取名单**：打开点名页或执行闪抽时默认使用的名单
- **默认抽奖名单**：打开抽奖页时默认使用的奖池

### 点击后禁用时间（闪抽）
**功能说明**：点击一次闪抽后禁用按钮的秒数，防止误触

## 显示设置

### 字体来源
**功能说明**：跟随全局字体或为抽取结果单独指定字体

- **跟随全局**：使用全局界面字体
- **自定义**：单独指定字体

### 自定义字体
字体族名称，留空时使用默认字体。

### 字体大小
**功能说明**：抽取结果文字大小

### 显示格式
**功能说明**：控制结果中显示名称、编号或两者

| 选项 | 说明 |
|------|------|
| **仅名称** | 只显示名称 |
| **仅编号** | 只显示编号 |
| **编号和名称** | 同时显示编号与名称 |

### 显示样式
**功能说明**：控制抽取结果的整体样式

- **默认**
- **卡片**

### 抽奖过程显示
**功能说明**：抽奖过程中候选结果的展示格式

可选预设格式（如"奖品/分组-名称"、"序号 奖品/分组-名称"等），或选择 **自定义显示格式**。

### 自定义显示格式
**功能说明**：设置抽奖过程的自定义展示格式，支持插入以下格式变量（点按变量即可插入）：

| 变量 | 说明 |
|------|------|
| 序号 | 成员/奖品序号 |
| 奖项 | 奖品信息 |
| 奖项 ID | 奖品 ID |
| 奖项名称 | 奖品名称 |
| 成员 | 成员信息 |
| 成员 ID | 成员 ID |
| 成员名字 | 成员名字 |
| 成员分组 | 成员分组 |
| 换行 | 换行符 |

::: tip
除换行符以外，其他分隔符（如空格、`-`、`/`）可直接输入。
:::

### 显示标签
**功能说明**：抽取结果中展示成员或奖品标签

### 权重透明化
**功能说明**：在结果展示中显示权重透明信息

## 动画设置

### 动画模式
**功能说明**：设置抽取动画播放方式

| 选项 | 说明 |
|------|------|
| **手动停止** | 点击"停止"时定格结果 |
| **自动播放** | 自动滚动候选结果，达到次数后自动定格 |
| **无动画** | 不播放动画，直接显示结果 |

### 动画间隔
**功能说明**：抽取动画每次切换的间隔（毫秒）

### 自动播放次数
**功能说明**：自动播放模式下滚动候选结果的次数

### 动画样式
**功能说明**：设置抽取过程和最终定格时使用的统一动画效果

- **直接轮换**：候选结果直接切换
- **淡入上浮**：候选结果淡入并上浮
- **左右晃动**：候选结果左右晃动

::: tip
点名、闪抽、抽奖使用相同的动画样式配置，抽取过程动画与最终结果展示保持一致。
:::
