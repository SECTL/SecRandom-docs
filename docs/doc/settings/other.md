# 更多设置

::: tip 版本提示
本文档对应 **v3** 的设置页面集合（页面管理、快捷键、更新、关于、日志等）。v3 处于 Alpha 阶段，设置项可能随版本调整，请以实际界面为准。
:::

> **深度定制** - 页面管理、全局快捷键、更新策略与关于信息，一页掌握。

## 页面管理

### 启用抽奖
**功能说明**：是否启用抽奖功能

- 开启：显示抽奖入口
- 关闭：隐藏抽奖入口，并拒绝抽奖快捷键和外部指令

### 点名控制面板位置
**功能说明**：设置点名页控制面板显示在主内容左侧或右侧

- 左侧 / 右侧

### 点名页面控件
**功能说明**：控制点名页侧边控制面板中的控件显示

可选控件：重置按钮、人数调节、开始按钮、名单选择、范围选择、性别选择、剩余名单按钮、人数统计

### 抽奖控制面板位置
**功能说明**：设置抽奖页控制面板显示在主内容左侧或右侧

- 左侧 / 右侧

### 抽奖页面控件
**功能说明**：控制抽奖页侧边控制面板中的控件显示

可选控件：重置按钮、数量调节、开始按钮、奖池选择、成员名单选择、范围选择、性别选择、剩余名单按钮、奖数统计

## 快捷键

### 启用快捷键
**功能说明**：启用全局快捷键响应

### 快捷键列表
| 快捷键 | 功能 |
|--------|------|
| 打开点名页 | 打开点名页面（例如 Ctrl+Alt+R） |
| 执行闪抽 | 执行快速抽取（例如 Ctrl+Alt+Q） |
| 打开抽奖页 | 打开抽奖页面（例如 Ctrl+Alt+L） |
| 增加点名人数 | 增加点名人数 |
| 减少点名人数 | 减少点名人数 |
| 增加抽奖数量 | 增加抽奖数量 |
| 减少抽奖数量 | 减少抽奖数量 |
| 开始或停止点名 | 开始或停止点名 |
| 开始或停止抽奖 | 开始或停止抽奖 |

### 设置快捷键
1. 展开对应快捷键设置项
2. 按下所需组合键（例如 `Ctrl+Alt+R`）
3. `Esc` 取消输入

**注意事项**：
- 已分配给其他操作的快捷键会提示"冲突"
- 可"清空快捷键"移除已设置组合

## 更新设置

### 自动更新模式
**功能说明**：自动检查发现的新版本，可选择通知、下载或安装

| 选项 | 说明 |
|------|------|
| **关闭** | 不自动检查更新 |
| **自动检查更新并通知** | 发现新版本时通知 |
| **自动检查更新并下载** | 自动下载新版本 |
| **自动检查更新并安装** | 自动下载并安装新版本 |

### 更新通道
**功能说明**：选择稳定版或预览版更新

- **稳定版**：正式版本
- **预览版**：预览版本（含测试版/开发版）

### 更新来源
**功能说明**：选择更新检查来源

| 选项 | 说明 |
|------|------|
| **自动选择（推荐）** | 依次尝试思拓创联官方、GitHub 镜像和 GitHub |
| **思拓创联** | 官方分发（只提供稳定版更新） |
| **GitHub 镜像** | GitHub 镜像源 |
| **GitHub** | GitHub 官方源 |

### 检查更新
点击 **"检查更新"** 检查当前通道的最新版本。仅检查已签名的完整发布清单，不会在后台下载更新。

**强制检查更新**：检查当前通道的最新版本，即使其低于当前版本。

### 更新状态
- 上次检查时间
- 更新状态：尚未检查 / 正在检查 / 当前已是最新版本 / 发现新版本 / 正在下载 / 正在验证 / 等待安装 / 正在重启应用更新

::: tip
更新部署前会验证已签名的发布清单以及制品的长度和哈希，确保安装包完整可信。
:::

在"日志查看器"页面可以查看程序运行日志，便于排查问题。也支持在软件内打开日志目录。

- **数据目录**：名单、历史、证明等数据位置
- **应用目录**：程序安装位置
