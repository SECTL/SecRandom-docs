# 更多设置

::: tip 版本提示
本文档对应 **v3** 的设置页面集合（页面管理、快捷键、更新、关于、日志等）。设置项可能随版本调整，请以实际界面为准。
:::

> **深度定制** - 页面管理、全局快捷键、更新策略与关于信息，一页掌握。

## 页面管理

### 启用抽奖
**功能说明**：是否启用抽奖功能

- 开启：显示抽奖入口
- 关闭：隐藏抽奖入口，并拒绝抽奖快捷键和外部指令

### 点名控制面板位置
**功能说明**：设置点名页控制面板显示在主内容左侧或右侧

- 左侧 / 右侧

### 点名页面控件
**功能说明**：控制点名页侧边控制面板中的控件显示

可选控件：重置按钮、人数调节、开始按钮、名单选择、范围选择、性别选择、剩余名单按钮、人数统计

### 抽奖控制面板位置
**功能说明**：设置抽奖页控制面板显示在主内容左侧或右侧

- 左侧 / 右侧

### 抽奖页面控件
**功能说明**：控制抽奖页侧边控制面板中的控件显示

可选控件：重置按钮、数量调节、开始按钮、奖池选择、成员名单选择、范围选择、性别选择、剩余名单按钮、奖数统计

## 快捷键

### 启用快捷键
**功能说明**：启用全局快捷键响应

### 快捷键列表
| 快捷键 | 功能 |
|--------|------|
| 打开点名页 | 打开点名页面（例如 Ctrl+Alt+R） |
| 执行闪抽 | 执行快速抽取（例如 Ctrl+Alt+Q） |
| 打开抽奖页 | 打开抽奖页面（例如 Ctrl+Alt+L） |
| 增加点名人数 | 增加点名人数 |
| 减少点名人数 | 减少点名人数 |
| 增加抽奖数量 | 增加抽奖数量 |
| 减少抽奖数量 | 减少抽奖数量 |
| 开始或停止点名 | 开始或停止点名 |
| 开始或停止抽奖 | 开始或停止抽奖 |

### 设置快捷键
1. 展开对应快捷键设置项
2. 按下所需组合键（例如 `Ctrl+Alt+R`）
3. `Esc` 取消输入

**注意事项**：
- 已分配给其他操作的快捷键会提示"冲突"
- 可"清空快捷键"移除已设置组合

## 更新设置

### 自动更新模式
**功能说明**：自动检查发现的新版本，可选择通知、下载或安装

| 选项 | 说明 |
|------|------|
| **关闭** | 不自动检查更新 |
| **自动检查更新并通知** | 发现新版本时通知 |
| **自动检查更新并下载** | 自动下载新版本 |
| **自动检查更新并安装** | 自动下载并安装新版本 |

### 更新通道
**功能说明**：选择稳定版或预览版更新

- **稳定版**：正式版本
- **预览版**：预览版本（含测试版/开发版）

### 更新来源
**功能说明**：选择更新检查来源

| 选项 | 说明 |
|------|------|
| **自动选择（推荐）** | 依次尝试思拓创联官方、GitHub 镜像和 GitHub |
| **思拓创联** | 官方分发（只提供稳定版更新） |
| **GitHub 镜像** | GitHub 镜像源 |
| **GitHub** | GitHub 官方源 |

### 检查更新
点击 **"检查更新"** 检查当前通道的最新版本。仅检查已签名的完整发布清单，不会在后台下载更新。

**强制检查更新**：检查当前通道的最新版本，即使其低于当前版本。

### 更新状态
- 上次检查时间
- 更新状态：尚未检查 / 正在检查 / 当前已是最新版本 / 发现新版本 / 正在下载 / 正在验证 / 等待安装 / 正在重启应用更新

::: tip
更新部署前会验证已签名的发布清单以及制品的长度和哈希，确保安装包完整可信。
:::

## 更多选项

设置页右上角的 **"更多选项..."** 菜单汇集了日志、诊断与数据迁移入口：

| 菜单项 | 说明 |
|--------|------|
| **查看日志** | 打开日志查看器（见下方"日志查看器"） |
| **导出诊断数据** | 立即导出脱敏的运行时信息与受限日志，用于排查问题 |
| **导出设置** | 将当前设置导出为 SecRandom v3 配置文件（`.json`） |
| **导入设置** | 仅从 SecRandom v3 配置文件导入设置，覆盖当前配置 |
| **导出所有数据** | 导出全部非凭据数据与设置（`.zip`） |
| **导入所有数据** | 仅从 SecRandom v3 备份导入全部数据 |
| **公告** | 打开公告页面 |
| **反馈** | 打开反馈抽屉，提交 Bug 或新功能建议 |
| **打开日志目录 / 数据目录 / 应用目录** | 直接在文件管理器中打开对应目录 |

### 导出诊断数据

提供 **标准诊断包** 与 **扩展诊断包** 两种：

- **标准诊断包**：包含全部经过脱敏处理的日志和运行时信息
- **扩展诊断包**：在标准包之外，还包含脱敏设置快照、档案数量摘要及脱敏崩溃报告

两种诊断包均不包含名单、历史原文或安全凭据。

### 导出 / 导入设置与全部数据

- **导出设置**与**导入设置**各有四种方式：**文件导出 / 从文件导入**、**扫码快速**、**无网**、**会话码**（传输方式说明见 [名单管理](/doc/settings/listmg)）
- **导出所有数据**会打包全部非凭据数据与设置；**导入所有数据**仅接受 SecRandom v3 备份

::: warning 导入前会自动创建快照
确认导入时会先自动创建恢复快照（导入设置创建设置快照，导入全部数据创建完整快照）；快照失败时不会导入。密码、TOTP、USB 绑定与锁定状态等安全凭据不会随设置或数据导入。
:::

## 日志查看器

在"日志查看器"页面可以查看程序运行日志，便于排查问题。也支持在软件内打开日志目录。

## 特定目录打开

支持在软件内打开：
- **日志目录**：运行日志位置
- **数据目录**：名单、历史、证明等数据位置
- **应用目录**：程序安装位置

## 公告

在"公告"页面可以查看官方发布的公告（支持置顶），点击 **"刷新公告"** 可重新拉取。加载失败时页面会提示无法连接公告服务，请检查网络后重试。

## 反馈

入口有两个：**更多选项... → 反馈**，以及崩溃恢复页的 **"应用内反馈"**。

**功能说明**：在软件内直接提交 Bug 反馈、新功能或优化体验建议

**操作方式**：
1. 选择反馈类型（Bug / 新功能 / 优化体验）
2. 按表单填写简要标题、期望行为、实际结果与重现步骤等说明
3. 可选填写联系邮箱，便于需要时回复
4. 点击 **"提交反馈"**

**注意事项**：
- 提交时会自动生成并上传与"导出诊断数据"相同的**脱敏 ZIP 附件**，用于问题定位
- 诊断 ZIP 超过上传限制时不会提交反馈，可清理日志后重试，或改用 [GitHub Issues](https://github.com/SECTL/SecRandom/issues)
