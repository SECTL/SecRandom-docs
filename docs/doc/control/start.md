# 快速开始

> 目标：**十分钟内**让第一台教室机出现在控制台的节点列表里，并能对它执行一次远程操作。

## 开始之前

| 需要准备 | 说明 |
|---|---|
| **思拓创联账号** | 控制台与设备端用的是同一个账号体系，不需要另外注册 |
| **SecRandom v3 桌面客户端** | 装在教室机上。手机端**不能**作为被集控的设备，但可以当遥控器用 |
| **能上网的校园网络** | 设备需要能连出到集控服务（出站长连接，一般不需要额外开放入站端口） |

## 第一步：在教室机上登录账号

1. 打开教室机上的 SecRandom，进入**设置**。
2. 在设置页的账号区域点击**登录**，按提示在浏览器里完成思拓创联账号授权。
3. 登录后账号区域会显示头像、昵称与用户 ID。

::: tip 为什么要先登录
设备端是用**这台机器上登录的账号**去连接集控服务的：账号必须是目标组的成员，否则连接会被拒绝。如果你在多台教室机上使用同一个账号，只需各自登录一次。
:::

## 第二步：在控制台创建组

1. 用浏览器打开 [secrandom-control.sectl.cn](https://secrandom-control.sectl.cn)，点击**登录**并完成思拓创联授权。
2. 进入控制台后点击**创建组**，为它起一个容易辨认的名字，例如「教学楼 3栋 2楼」「高一(3)班 · 讲台机」。建议写成「**班级 · 位置**」的形式，方便在多个组之间切换时快速辨认。
3. 创建成功后，你就是这个组的**创建者（owner）**。组的详情页里会显示**组 ID**，下一步要用到它。

::: info 一个组就是一条权限边界
一个组 ≈ 一个管理单元（年级 / 校区 / 机房）。不同教室的人不一样，需要隔离就多建几个组。不属于某个组的人，在该组里**看不到任何内容**。
:::

## 第三步（可选）：邀请他人加入

1. 进入组的**邀请**页签（需要管理员及以上角色），点击**新建邀请**。
2. 选择要赋予的角色（只能邀请**低于自己等级**的角色，创建者只能通过「转让」产生）。
3. 复制生成的**邀请链接**或**邀请码**发给对方。对方登录后兑换即可入组，拿到的是邀请时指定的角色。

::: warning 邀请码请私发
邀请码**一次有效、创建后 72 小时过期**，请不要转发到公开群。对象收到后把整条链接粘贴进加入页即可，系统会自动取出其中的邀请码。撤销后立即失效，已兑换的不受影响。
:::

## 第四步：在设备上打开集控

在教室机上进入**设置 → 通用 → 集控**（仅桌面端有这一页）：

| 设置项 | 怎么填 |
|---|---|
| **所属组 ID** | 粘贴上一步控制台里的**组 ID** |
| **节点通道地址** | 保持默认（线上节点通道），一般不需要修改 |
| **节点 ID** | 安装时生成，长期保持不变，**不用改** |
| **显示名称** | 建议填「301班讲台机」这类名字；留空则上报本机主机名 |
| **允许被远程控制** | **打开** |

改完立即生效，这一页没有「保存」按钮。

::: tip 打开开关意味着什么
「允许被远程控制」是**这台机器自己的闸**。打开后，组内角色足够的人才能对它下发操作；关掉后，无论服务端下发什么命令都不会执行。详见[设备端设置](/doc/control/device)。
:::

## 第五步：回到控制台确认上线

进入组的**节点**页签，稍等片刻（设备连上来后列表会自动刷新），你应该能看到这台机器，并显示**在线**。

::: info 不需要「手动注册设备」
集控采用的是**连接即登记**：教室机登录组内成员账号、填对组 ID 并打开开关后，第一次连接就会被登记进节点列表。列表里的**设备名、能力清单、本机开关状态都由设备自己上报**，控制台改不了。
:::

## 第六步：试一次远程操作

打开该设备的**详情页**（点击节点 ID 进入）：

- **禁止抽取 / 允许抽取** —— 期望状态，设备离线时也照样生效，它上线后自动收敛
- **立即抽取** —— 动作型命令，按钮需要**连点两次**才会下发（第一次进入待确认，4 秒内再点一次才真正下发），并且带有过期时间，过期即丢弃、绝不补执行
- **播报一句话** —— 用那台设备本机的语音引擎播报，正文不超过 200 字

也可以用手机端当遥控器：在手机 SecRandom 上登录同一账号，进入**抽取 → 远程抽取**，选择分组、设备与名单后点抽取。

## 卡住了？常见卡点对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 设备端连接状态显示**等待登录或填写组 ID** | 账号没登录，或组 ID 空着 | 先登录账号，再填入组 ID |
| 设备端显示**尚未登录 SECTL 账号** | 这台机器还没登录 | 在设备上登录思拓创联账号 |
| 设备端显示**组不存在，或当前账号不是该组成员** | 设备登录的账号不是该组成员 | 用组内的邀请码把该账号邀请进组，或换成已在组内的账号登录 |
| 设备端显示**该组下没有这个节点，请先在控制台注册** | 服务端关闭了自动登记，或组 ID 填错了 | 核对组 ID；若确认无误请联系管理员 |
| 设备端显示**已停止重试** | 出现了重试也没有意义的失败（凭据 / 组 / 格式） | 按旁边的说明修正后点**立即重连** |
| 控制台节点列表里没有这台机器 | 设备未连上，或账号不是成员 | 先看设备端的状态与说明文字，再回到第四步核对 |
| 控制台显示**本机已禁用远控** | 设备自己把开关关掉了 | 这是设备的权力，只能到设备上重新打开 |
| 控制台显示**禁止抽取中** | 控制台下发了「禁止抽取」期望状态 | 在节点详情页点**允许抽取** |

更细的排查见[常见问题](/doc/control/faq)。
