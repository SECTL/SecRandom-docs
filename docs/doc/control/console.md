# 控制台使用

> 控制台地址：[secrandom-control.sectl.cn](https://secrandom-control.sectl.cn)，用**思拓创联账号**登录。

## 登录与会话

- 点击**登录**后会整页跳转到思拓创联完成授权，再回到控制台；已登录时首页会直接给「进入控制台」。
- **浏览器只保存一个不透明的会话标识**，思拓创联的访问令牌保存在服务端，不会出现在浏览器里。
- 会话会定期回思拓创联复核：**在官网退出登录后，控制台这边的会话也会随之失效**，需要重新登录。
- 从站外直接打开控制台链接时，会重新校验一次会话；控制台内部的页面切换不会重复跳转。
- 若服务端暂时不可用，登录页会提示「服务暂时不可用」，此时**不会**把你弹到授权页，重试即可。

## 首页：我的组

| 区域 | 说明 |
|---|---|
| **我的组** | 你是**创建者**的组（转让出去后即从这一栏消失，也不占用名额） |
| **加入的组** | 别人邀请你加入的组 |
| **创建组** | 新建一个组并成为创建者，组名建议写成「班级 · 位置」 |
| **输入邀请码加入** | 粘贴邀请链接或邀请码即可入组 |
| **排序** | 组的显示顺序是你的账号偏好，保存在服务端，换电脑也在 |

::: info 建组上限
一个账号**拥有**（创建者身份）的组默认最多 **100 个**，界面会显示「已拥有 / 上限」的进度。到达上限后需要先把不再需要的组**转让**给他人，才能继续建组。
:::

## 组详情页

打开任意组后，页头显示**节点总数、在线、禁止抽取中、成员**四项统计，以及**组 ID**；页面里是四个页签：

| 页签 | 谁能看 | 说明 |
|---|---|---|
| **节点** | 全部成员 | 设备列表、筛选与批量操作 |
| **成员** | 全部成员（可改的按角色裁剪） | 成员列表、改角色、移除 |
| **邀请** | 管理员及以上 | 邀请码与邀请链接的管理 |
| **审计日志** | 管理员及以上 | 操作留痕与导出 |

管理员及以上还可以**重命名组**（组名不能为空，且不超过 64 个字符）。创建者可以发起**转让**。

## 成员与角色

组内是**四档单层权限**，等级越高权限越大：

| 角色 | 能做什么 |
|---|---|
| **查看者** | 只看状态与汇总（节点列表、在线情况、设备信息） |
| **操作者** | 查看者 + 远控：允许 / 禁止抽取、触发抽取、展示与播报；可**读取**设备设置 |
| **管理员** | 操作者 + 改设置、改名单（含读取名单）+ 管成员 + 管节点登记 + 看审计 + 重命名组 |
| **创建者** | 全部权限，含组转让；全组唯一 |

每项远程能力对应的**最低角色**：

| 能力 | 含义 | 最低角色 |
|---|---|---|
| `node.status.read` | 读取状态 | 查看者 |
| `proof.list` | 读取证明列表 | 查看者 |
| `draw.lock` | 禁止 / 允许抽取 | 操作者 |
| `draw.trigger` | 触发一次抽取 | 操作者 |
| `media.play` | 展示结果 / 播报 | 操作者 |
| `settings.read` | 读取设置 | 操作者 |
| `settings.write` | 修改设置 | 管理员 |
| `roster.read` | 读取名单 | 管理员 |
| `roster.write` | 修改名单 | 管理员 |

四条成员管理约束（缺一条都会产生提权路径）：

1. 只能邀请**低于自己等级**的成员；
2. 不能修改或移除**同级及更高等级**的成员；
3. 不能给自己提权；
4. **创建者全组唯一**：不能被移除，也不能被直接授予，只能通过「转让」产生。

::: tip 界面裁剪 ≠ 安全边界
界面会按你的角色隐藏不支持的按钮，看起来「点不到」；但真正的判定始终在服务端。反过来也一样：**操作按钮还会按设备自己声明的能力裁剪**，设备没声明某项能力时，相关按钮不会出现，避免「点了没反应」。
:::

## 邀请他人加入

1. 进入**邀请**页签（管理员及以上），点击**新建邀请**。
2. 选择**赋予的角色**——只能邀请低于自己等级的角色，且永远不含创建者；默认选中「操作者」。
3. 生成后可以**复制链接**（形如 `…/join?code=…`）发给对方，也可以只把**邀请码**告诉对方。
4. 列表里能看到邀请码、角色、创建者、过期时间与状态（待兑换 / 已兑换 / 已过期 / 已撤销），未兑换的可以**撤销**。

规则与注意事项：

- 邀请码**一次有效**，**创建后 72 小时过期**，请**不要转发到公开群**；
- 对方需要先登录思拓创联账号才能兑换；登录后邀请码会保留，不会因为中间跳一次登录而丢失；
- 兑换后获得的角色**就是邀请时指定的角色**；
- 撤销后邀请码立刻失效，**已被兑换的不受影响**。

## 转让创建者

创建者可以把身份交给组内另一位成员，**需要双方确认**：

1. 创建者在组详情页选择一位成员，点击**发送转让请求**；
2. 此时**权限没有任何变化**，对方会在自己的会话里看到「有人要把创建者转让给你」；
3. 对方点击**接受并成为创建者**后，原创建者降为**管理员**；
4. 对方拒绝、或超过有效期（由服务端配置，默认 48 小时；界面会显示具体截止时间）则自动作废，权限不变，可以重新发起。

## 节点页签：设备列表

列表里每台设备显示：

| 信息 | 说明 |
|---|---|
| **在线 / 离线** | 由服务端按最后心跳判定，页面每 10 秒自动刷新，上下线也会即时推送 |
| **设备名** | 设备自己设置并上报的名字；没设置时显示「未命名（可在该设备的客户端上设置）」 |
| **节点 ID** | 设备的唯一标识，点击进入详情页。**名字可以重复、重装会丢，只有节点 ID 能钉死一台机器** |
| **平台 / 版本** | 例如 Windows / 3.x.y |
| **禁止抽取中** | **控制台下发**的期望状态 |
| **本机已禁用远控** | **设备自己上报**的开关状态，控制台无法改成别的值 |
| **能力清单** | 展开该行可见，决定这一行上哪些操作可用 |
| **最后心跳 / 首次登记** | 便于判断「这台机器是不是换了机器 / 长期失联」 |

筛选与批量：

- 筛选：**只看在线**、**只看禁止抽取中**，可随时清除；
- 勾选只作用于**当前筛选结果**，选择不落库、刷新即失效；
- 批量操作（操作者及以上）：**批量禁止抽取**、**批量允许抽取**、**批量播报**（不超过 200 字，用各台设备本机的语音引擎，正在抽取的机器会拒绝）；
- 批量移除（管理员及以上）：**逐台下发**，没有「全组一键」这种按钮——那是最容易误操作全教室的做法；
- 勾选但**不支持该能力**的设备会被明确跳过并报数，例如「有 N 台没有声明「禁止 / 允许抽取」能力，已跳过」；
- 批量结论会区分「已完成 / 部分完成 / 失败」，并**列出失败设备的 ID**。

::: warning 移除节点不是拉黑
移除节点只是**清理这条登记记录**，不能阻止这台机器再次接入；那位成员还在组里的话，机器重新连上来就会重新出现。要彻底禁止，请**移除成员**。
:::

## 节点详情页

页头永远显示设备名、在线状态、**禁止抽取中**、**本机已禁用远控**、节点 ID、平台、版本、最后心跳、首次登记与能力清单。下面是四个页签：

### 总览

- **状态小结**：连接、抽取开关（控制台下发）、本机远控、最近一条命令；
- **抽取开关（期望状态）**：显示 `revision` 与是否已投递；设备离线时提示「设置已落库，它上线后自动收敛」；
- **操作**：禁止 / 允许抽取、立即抽取、移除节点（管理员及以上）、播报一句话；
- **抽取设置**（默认收起）：可选择「快抽（设备默认名单）」或「点名单」，后者可指定名单、性别、分组、人数——**只作用于这一次下发，不改设备上的默认设置**；控制台还会用已读到的名单做一次**本机预检**，提前告诉你为什么可能发不出去；
- **命令回执面板**：显示状态、命令 ID 与「设备返回」的原因；原因码会被翻译成中文并尽量给出下一步动作（例如语音总开关关着时给「打开语音」按钮）；
- **最近一次抽取**：显示抽到了谁、名单与人数。

### 设置

- **必须先点「从设备读取」才能修改**：读取之前整页控件是禁用的（页面照常显示，但改不了）；
- 设置项的名称与说明来自客户端自己的设置页，按控制台当前语言显示；**当前值、取值范围、能否远程修改以设备上报为准**；
- 逐项有三种状态要分清：**不可远程修改**（设备说不能改）、**未读取**（设备没上报这一项的值）、**待下发**（你改了草稿还没提交）；
- **永远不能远程修改**的四类：**安全设置、集控设置、桌面集成（开机自启、协议注册）、更新设置**——设备会直接拒绝对白名单之外的路径，这是刻意的（能远程开自启、改安全策略，等于把设备所有权交出去）；
- 提交时是**全有或全无**：只发送「改过且可写」的项，有一项不合法就整条不下发；
- 下发成功后会**再读一次设备**并提示「界面与设备当前值对齐」；
- 设置没有「回滚 / 还原」入口，改动前请确认。

### 名单

- **点名名单**与**抽奖名单**（奖池）是同一页的两个分段，**各有各的草稿**，来回切换不会丢；
- 先点**读取设备名单**（管理员及以上）：这是集控里**最敏感的一条只读通道**，因为名单包含学生姓名；
- 读取后可以就地编辑、添加行、**从文件导入**（支持 `.xlsx / .xls / .xlsm / .csv / .tsv / .txt`，导入前可指定工作表、表头行、起止行与列对应并预览）、**导出 CSV**；
- **导入只改控制台里的草稿**，还要点**下发草稿**才会写到设备上；
- 下发有两种模式：
  - **只增改（默认）**：只更新你改动的成员，不会删除别人；
  - **整份覆盖**：**缺的人会被删除**——确认框里会明确写出来；
- 名单较大时设备只会回传一部分并标记**已截断**，此时界面会提示改用「只增改」，因为「整份覆盖」会把没回传的人删掉；
- 一次导入的行数有上限（当前为 2000 行），超出会拒绝并提示；
- 下发名单**默认不会切换设备当前正在使用的那份名单**（避免打断正在上课的机器）；
- 设备在写入新名单前，会自动把上一版备份到本机的 `data/backup/roster/` 目录。

### 命令记录

只记录**本次打开页面后由你下发的命令**，最新在最上面，刷新页面即清空。真正的操作留痕在**审计日志**里。

## 命令回执：看状态，而不是「下发成功」

「发送成功」与「执行成功」是两件事，命令的状态含义如下：

| 状态 | 含义 |
|---|---|
| **排队中** | 设备离线，等它上线补投（若届时已过期，则不会执行） |
| **已投递** | 命令已送到设备，尚未收到执行结果 |
| **设备已接受** | 设备正在执行 |
| **执行完成** | 成功 |
| **设备拒绝** | 配置问题（例如本机开关关着、能力未声明、设置项不可远程修改），不是运行故障 |
| **执行失败** | 设备接受了但执行过程中出错 |

几个常见原因（界面会给出对应说明）：

- 「这台机器本机开关关着（设备自己关的，控制台改不了）」——去设备上打开开关；
- 「设备限流了：N 秒内最多接受 M 条命令，请稍后重试」——不要连续猛点；
- 「这条命令在设备收到之前就过期了。动作命令过期即丢弃，绝不补执行，请重新下发」；
- 「设备拒绝了这条命令：设置项 … 不允许远程修改」——见上面「设置」一节的白名单。

## 审计日志

- **仅管理员及以上可见**：审计含成员与设备信息；
- 记录的事件覆盖：建组 / 改名、成员邀请 / 加入 / 改角色 / 移除、邀请创建 / 撤销、转让请求 / 确认 / 拒绝 / 超时、节点登记、策略下发；
- 每条记录包含时间、事件、对象、明细、操作人、来源设备（浏览器会话 / App 端）与结果（成功 / 被拒绝 / 失败）；
- **被拒绝的越权尝试同样会留痕**（结果为「被拒绝」）；
- 支持按事件类型、结果、时间范围、来源设备、被操作设备、操作者筛选，筛选在服务端执行；
- 支持**导出 CSV**（导出的是当前筛选下的记录，最多 5000 条，超出时会提示缩小范围后重导）；
- 审计**不会记录凭据、令牌或学生姓名**，明细里只放可公开的短字符串（例如角色名、拒绝原因）。

::: warning 关于保留时长
审计记录的**保留周期目前没有对外承诺**，请以实际界面与官方说明为准；需要长期留档时建议定期自行导出 CSV。
:::
