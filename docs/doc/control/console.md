# 控制台

> 地址：[secrandom-control.sectl.cn](https://secrandom-control.sectl.cn)，用思拓创联账号登录。

## 登录

点击「登录」会跳到思拓创联完成授权，再回到控制台。浏览器里不保存你的账号令牌；**在思拓创联官网退出登录后，控制台这边也会失效**，需要重新登录。

## 组就是权限边界

一个组 ≈ 一个管理单元（年级、校区、机房）。**不属于某个组的人，在里面看不到任何内容**，所以想让两批人互相看不见，就分成两个组。

- 建组的人自动成为**创建者**，组详情页里显示的**组 ID** 就是设备入组要填的那串；
- 一个账号最多拥有 100 个组，到上限可以**转让**或**解散**不再需要的组，两种都会释放名额；
- 组名建议写成「班级 · 位置」，方便在多个组之间辨认。

### 解散组（不可恢复）

只有**创建者**能解散。入口在组的危险区，提交时要在确认框里**原样输入组名**。解散后：

- 组内**所有成员立刻失去访问权限**；
- 邀请码、设备登记、命令记录、抽取设置**一并删除，无法恢复**；
- 在线的教室机会被断开，随后按「组不存在或不是成员」重连失败；
- 重建出来的是**另一个组**（组 ID 不同），设备要重新填新的组 ID。

::: warning 解散前先导出审计
组没了之后，这个组的审计页也打不开。需要留档请在解散前先导出 CSV。
:::

## 成员与四种角色

| 角色 | 能做什么 |
|---|---|
| **查看者** | 只看状态：设备列表、在线情况、设备信息 |
| **操作者** | 还能远控：锁定 / 允许抽取、发起抽取、重置本轮、播报；可读取设备设置 |
| **管理员** | 还能改设置、读写名单与奖池、管成员、管设备登记、看审计、改组名 |
| **创建者** | 全部权限，并且是唯一能转让与解散组的人 |

两条硬规则：

- **只能邀请或管理等级低于自己的人**，不能给自己提权，也不能改动同级及以上的人；
- **创建者全组唯一**：不能被移除、不能被直接授予，只能通过**转让**产生。

界面上看不到的按钮，通常是你的角色不够；设备上的操作按钮还会按「那台设备是否支持」来显示。

## 邀请他人

在组的**邀请**页签新建邀请，选好角色，把**链接或邀请码**发给对方，对方登录后兑换即可加入。

- 邀请码**一次有效、创建后 72 小时过期**，请不要转发到公开群；
- 加入后得到的角色，就是你邀请时选的那个；
- 未兑换的可以撤销，**已兑换的不受影响**。

## 转让创建者

创建者可以发起转让：选一位成员 → 对方在自己的会话里确认 → 你降为管理员。**确认之前权限不变**；对方拒绝或超时会自动作废，可以重新发起。交接请用转让，不要解散重建。

## 设备列表

每台设备都能看到：在线状态、设备名、节点 ID、平台与版本、是否被禁止抽取、是否本机关闭了远控、最后上报时间；展开一行还能看到它**支持哪些操作**。

- 可以筛选「只看在线」「只看被禁止抽取的」；
- 勾选后可**批量**锁定 / 允许抽取、批量播报；批量是逐台下发的，界面会告诉你哪几台失败；
- **移除设备只是删掉这条登记，不是拉黑**：那位成员还在组里，机器重新连上来就又会出现在列表里。要彻底禁止，请**移除成员**。

## 审计日志

**管理员及以上**可查看。记录建组 / 改名 / **解散**、成员邀请 / 加入 / 改角色 / 移除、邀请创建 / 撤销、转让、设备登记、各类下发与**撤销排队命令**，以及**被拒绝的越权尝试**；每条带时间、操作人、来源设备（浏览器还是手机）与结果。

- 可按时间、事件、结果、设备、操作人筛选；
- 可**导出 CSV**（导出当前筛选结果，最多 5000 条）；
- 审计**不记录密码、令牌或学生姓名**。

::: warning 保留期
审计的保留时长目前没有对外承诺，需要长期留档请定期导出。
:::
