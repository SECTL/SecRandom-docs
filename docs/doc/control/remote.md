# 远程操作与设备

> 这一页讲两件事：你能对教室机做什么，以及教室机上那个开关怎么用。

## 你能远程做什么

打开某台设备的详情页，可以：

| 操作 | 需要角色 | 说明 |
|---|---|---|
| **禁止 / 允许抽取** | 操作者 | 设置后**设备离线也照样生效**，它上线自动生效；被锁定的机器本机也抽不了 |
| **立即抽取** | 操作者 | 让那台机器抽一次，见下 |
| **重置本轮** | 操作者 | 清空本轮的抽取进度，让这一轮重新开始 |
| **播报一句话** | 操作者 | 用那台机器自己的语音引擎念出来 |
| **改设置** | 管理员 | 只能改设备允许远程改的项 |
| **读名单 / 下发名单** | 管理员 | 点名名单与奖池都能远程更新 |

::: tip 「做一次」的操作不会延迟执行
「立即抽取」「播报」「重置本轮」这类操作带**过期时间**：设备离线时会先排队，等它上线补投；如果那时已经过期，就直接作废。

如果你改主意了，**排队中的命令可以直接撤销**（点两次「撤销」），设备上线后不会执行它；已经投递到设备上的就撤不回来了。另外「立即抽取」和「重置本轮」按钮都需要**点两次**才会真正下发。
:::

### 立即抽取有三种方式

| 方式 | 说明 |
|---|---|
| **快抽** | 不带任何条件：设备按自己的默认名单抽 1 个 |
| **点名单** | 指定名单、性别、分组与人数 |
| **抽奖池** | 在指定奖池里抽 N 个奖项；抽奖不按性别与分组筛选 |

- 名单与奖池的选项来自你**从设备读回来的数据**，不用手打；
- 可抽人数以名单里符合条件的人数为准，抽奖则以奖池里还剩的数量为准，超出会被拒绝并告诉你范围；
- 结果会回传显示：抽到了谁，或抽到几个奖品。

### 重置本轮

用在「这一轮重新开始」的时候，例如一节课结束、下一次课要重新点名。

- 只清空**本轮抽取进度**（这一轮里谁已经被抽到过、哪些奖品已经抽走），**不影响历史记录**；
- 教室机屏幕上的上一轮结果也会一起清掉，回到「还没抽过」的状态；
- 可以指定对象：点名（默认）/ 快速抽取 / 抽奖，也可以只重置某一份名单；
- 需要确认一次（手机上要连点两次）；设备**正在抽取**时会拒绝，等这一轮抽完再重置。

### 播报

- 用**那台设备本机的语音引擎**播报，正文不超过 200 字；
- 可选「显示闪抽窗口」，以及临时调整系统音量 / 播报音量，**播完恢复原值**：注意「不修改」和「设为 0（静音）」是两件事；
- 设备关闭了语音总开关时不会出声，界面上会给出打开语音的入口。

### 改设置

- **必须先「从设备读取」才能修改**，下发即生效，不需要重启设备；
- **安全设置、集控自身设置、桌面集成（开机自启、协议注册）、更新设置、备份设置、证明留存期**等永远不能远程改，界面会标成「不可远程修改」；
- 一批改动里只要有一项不合法，**整批都不会应用**。

### 名单与奖池

- 读取设备名单需要**管理员及以上**，因为名单里有学生姓名；
- 可以在控制台就地编辑、**从表格文件导入**（`.xlsx`、`.xls`、`.csv` 等）或导出 CSV；
- 导入只改控制台里的草稿，点**下发**才会写到设备上；
- 下发有两种模式：**只增改（默认）**不会删人；**整份覆盖**会**删掉没写进去的人**——名单很大时界面会提示你不要用覆盖；
- 下发**不会**切换设备当前正在使用的那份名单，也不会打断正在上课的机器。

## 什么时候会被拒绝

即使角色足够，设备也可能拒绝，界面上会说明原因：

- **本机开关关着** —— 只能到那台机器上打开；
- **抽取被锁定** —— 先「允许抽取」；
- **设备正在抽取** —— 等这一轮结束；
- **需要本机验证** —— 那台机器设了密码 / TOTP / U 盘保护，远程不会拉起验证框；
- **上课时间限制** —— 设备启用了课程联动；
- **设备不支持** —— 例如没开启抽奖功能、没有语音；
- **命令已过期** —— 重新下发即可；
- **下发太频繁** —— 稍等再试。

被拒绝时界面都会说明原因，部分提示还会带一个错误码；反馈问题时把错误码一并提供给官方，定位会快很多。

## 设备上的那个开关

教室机上：**设置 → 通用 → 集控**。

| 项目 | 说明 |
|---|---|
| **允许被远程控制** | 总开关。关掉后**不连接、也不执行任何远程操作**，控制台无法替你打开 |
| **所属组 ID** | 从控制台复制过来。这台机器上登录的账号**需要是这个组的成员**（自己建的组、被邀请加入的组都行），**不要求所有机器用同一个账号** |
| **节点通道地址** | 保持默认即可，一般不用动 |
| **节点 ID** | 安装时生成、长期不变，只读 |
| **显示名称** | 控制台里显示的名字；留空则用主机名 |
| **连接状态** | 已连接 / 等待重连 / 已停止重试等；旁边可点**立即重连** |

- 改完立即生效，这一页没有「保存」按钮；
- 断网或服务抖动时设备会自动重连，不用人工处理；
- **关掉开关就等于退出集控**：连接断开，之前下发的「禁止抽取」也不再约束本机；
- 这个开关与已生效的锁定状态单独保存，**导入设置或恢复备份都不会把它打开**；
- 手机上不显示这一页；**平板两个都支持**（既能被远程管理，也能当遥控器）。

## 手机与平板

| 设备 | 能做什么 |
|---|---|
| **手机** | 只当遥控器：在底部导航的「远程抽取」里选设备与名单，切换**点名 / 抽奖**，下发抽取或**重置本轮** |
| **平板** | 既能远程抽取（主界面里就有），也能被远程管理（设置里有「集控」页） |

手机端权限与控制台一致：读名单要管理员及以上，下发抽取要操作者及以上。手机上点下抽取后，**实际抽取发生在教室机上**，结果回传到手机。
