# 常见问题

## 开始使用

### 集控需要额外安装什么吗？

不需要单独安装「集控端」。控制台是网页，直接在浏览器里打开 [secrandom-control.sectl.cn](https://secrandom-control.sectl.cn)；被管理的教室机只需要安装 **SecRandom v3 桌面客户端**，在**设置 → 通用 → 集控**里打开开关即可。

### 手机端能做什么？

手机端**不是**被控设备，而是**遥控器**：登录同一账号后，在**抽取 → 远程抽取**里选设备、读名单、选条件并下发抽取，实际抽取发生在教室机上。手机端没有「集控」设置页。

### 一台教室机能同时属于两个组吗？

不能。设备设置里只有**一个**「所属组 ID」，改掉它就会改连到另一个组（控制台里会作为另一个组的节点出现）。

### 设备上的「显示名称」在哪里改？

在**那台设备**的 **设置 → 通用 → 集控 → 显示名称** 里改。它是设备自己的权威，控制台只能显示、不能改（设备从没连过时，控制台可以先给一个初始名）。

## 设备连不上 / 看不到设备

### 控制台里看不到我的教室机，怎么排查？

按顺序检查四件事：

1. 设备上**是否登录了思拓创联账号**（未登录时状态是「等待登录或填写组 ID」→ 说明「尚未登录 SECTL 账号」）；
2. **所属组 ID 是否填对**（建议直接从控制台复制粘贴）；
3. **「允许被远程控制」是否打开**；
4. **登录的那个账号是否在该组里**（不在组里会被拒绝，说明「组不存在，或当前账号不是该组成员」）。

::: tip 不需要手动「注册设备」
只要设备登录的是**组内成员账号**、组 ID 正确、开关打开，它连上来就会**自动出现在节点列表**里（连接即登记）。列表里没有它，通常是上面四件事之一。
:::

### 设备显示「已停止重试」怎么办？

说明遇到了**重试也没有意义**的问题。看状态旁边的说明文字：

- 「尚未登录 SECTL 账号」→ 去登录；
- 「还没有填写所属组 ID」→ 填入组 ID；
- 「组不存在，或当前账号不是该组成员」→ 用邀请码把该账号加入组；
- 「该组下没有这个节点，请先在控制台注册」→ 请管理员在控制台登记这台设备的**节点 ID**；
- 「服务端拒绝了本机节点凭据…」→ 联系官方处理。

修正后点**立即重连**。

### 设备一会在线一会离线？

设备主动保持一条长连接，约 25 秒一次心跳；服务端超过约 75 秒收不到心跳就判为离线，控制台页面每 10 秒刷新一次。短暂波动通常来自校园网抖动，网络恢复后设备会**自动退避重连**，不需要人工干预。

## 远程操作

### 点了「立即抽取」，设备没反应？

先看**命令回执**：

- **排队中** → 设备当前离线，等它上线补投；**如果届时已经过期，就不会执行**；
- **命令已过期** → 动作命令过期即丢弃、绝不补执行，重新下发即可；
- **设备拒绝了** → 按界面给出的原因处理（本机开关关着 / 抽取被锁定 / 正在抽取 / 需要本机验证 / 上课时间限制等）。

### 「禁止抽取」点了之后，设备离线还算数吗？

算数。它是**期望状态**：设好之后即使设备离线也照样生效，设备上线会自动收敛。注意两点：

- 被锁定的设备**本机也不能抽**；
- 如果那台设备**关掉了本机的「允许被远程控制」开关**，之前下发的锁定就不再影响它——收回远控权等于收回所有远程约束。

### 为什么显示「本机已禁用远控」？

这是**设备自己**把开关关掉了。控制台没有任何办法打开它，只能到那台机器上重新打开。这也是设计的一部分：远程说了不算，设备说了算。

### 为什么我改不了设置、也读不了名单？

检查角色：**读取设置**需要操作者及以上，**修改设置**、**读取名单**、**下发名单**需要管理员及以上。角色不足时按钮会自动隐藏或置灰。另外：

- 设置页必须**先点「从设备读取」**才能修改；
- **安全设置、集控自身设置、桌面集成（开机自启 / 协议注册）、更新设置、备份设置、证明留存期**等**永远不能远程修改**（界面会显示但标记「不可远程修改」）。

### 播报没有声音？

常见原因：

- 那台设备**关闭了语音总开关**——界面会提示「这台机器关闭了语音总开关，远程播报不会出声」，管理员及以上可以点**打开语音**一键修复；
- 播报音量这次被设成了 0（静音）：0 是「设为静音」，与「不修改」是两件事；
- 设备正在抽取，命令被拒绝。

### 提示「命令太频繁」怎么办？

设备自带限流（默认约 10 秒内最多 20 条命令），短时间内连续下发会被拒绝，并告知具体窗口与条数。稍等片刻再试即可。

## 组、邀请与权限

### 邀请码过期了 / 被别人用过了？

邀请码**一次有效、创建后 72 小时过期**，请让邀请人在组的**邀请**页签重新生成一个；已经作废或撤销的邀请码不会影响已加入的成员。

### 一个账号最多能建几个组？

默认 **100 个**（以界面显示的进度为准）。到达上限需要先把不再需要的组**转让**给他人。

### 怎么把某人彻底移出集控？

在组的**成员**列表里**移除该成员**——移除后该账号立刻失去本组的全部权限。注意：**移除节点不是拉黑**，只是清理登记记录；只要那位成员还在组里，机器重新连上来就会重新出现。

### 创建者（owner）能转让吗？能删除吗？

- 可以**转让**：需要**双方确认**，确认前权限不变，超时作废；转让成功后原创建者降为管理员；
- **不能删除**：创建者全组唯一，不能被移除，也不能被他人直接授予，只能通过转让产生。

## 数据与开源

### 学生姓名会被上传吗？

名单**不会随连接持续上传**：只有具备**管理员及以上**角色的人主动点「读取设备名单」时，设备才把名单回传；远程播报的正文不会写进日志；审计也**不记录学生姓名**。请按学校的个人信息管理要求存放导出的名单与审计 CSV。

### 集控开源吗？

- **服务端与 Web 控制台目前尚未开源**。公开仓库 [SECTL/SecRandom-Control-Console](https://github.com/SECTL/SecRandom-Control-Console) 目前包含许可、信任边界与接入说明；后续条件允许时会补齐控制台源码与协议规范。
- **设备端的集控实现随客户端一同公开**，见 [SECTL/SecRandom](https://github.com/SECTL/SecRandom)（GPL-3.0）。

### 能自己部署一套集控服务端吗？

暂时不能。协议是公开的，但服务端实现不开源，**官方尚未提供自建方式**，目前只有官方托管的服务。

### 审计记录会保留多久？

**目前没有对外承诺的保留周期**，需要长期留档时请定期在审计页签**导出 CSV**（导出上限 5000 条，超出时先筛选缩小范围）。
