当前 **v3 版本仍处于 Alpha 阶段**，请勿在生产环境使用。当前版本可能存在未知 Bug，仅供用户体验。

## 系统要求检查

### 硬件要求
| 类别 | 最低 | 推荐 |
|------|------|------|
| **处理器** | 主频 1GHz 64位双核 | 4核心及以上 |
| **内存** | 200MB 可用内存 | 8GB+ 整机内存 |
| **存储** | 1GB 可用空间 | - |
| **显示器** | 1024×768 分辨率 | 推荐1080p |

### 软件环境
| 使用方式 | 系统要求 |
|----------|----------|
| **Windows** | Windows 10/11（x64、x86、arm64） |
| **Linux** | 主流发行版（x64、arm64，提供 .deb 等格式） |
| **macOS** | macOS（x64、arm64） |
| **Android** | Android 移动端（arm64） |
| **iOS** | iOS 移动端（arm64，开发中） |

::: tip
SecRandom v3 为自包含发布，**无需额外安装 Python 或 .NET 运行时**。绝大部分 2017 年后出厂的一体机/办公电脑均满足最低或推荐配置要求。
:::

## 快速开始

### 1. 下载安装

从[下载页面](/download)获取最新版本。下载页会根据你的操作系统自动推荐合适的安装包，也可手动选择文件：

- **Windows**：`Windows-Setup` 为安装版，`Windows-Portable` 为便携版
- **Linux**：`.deb` 安装包（x64/arm64）
- **macOS**：`.dmg` 安装包
- **Android**：`.apk` 安装包

#### 版本通道
下载页支持按通道筛选版本：
- **stable**：稳定正式版
- **beta**：预览版本，后缀之后的数字表示预览版本的迭代次数
- **alpha**：开发版本，后缀之后的数字表示开发版本的迭代次数

::: tip
建议使用多线程下载工具以提升下载速度。
:::

文件下载完成后：

- **Windows 用户**：
  - 安装版：双击安装包，按照提示进行安装
  - 便携版：将压缩包解压到你想让软件长期存放的位置

  ::: info 如何找到下载的文件
  - 对于大部分浏览器，下载的文件位于"下载"文件夹中。可以在文件资源管理器中打开"下载"文件夹，找到下载的文件。
  - 部分浏览器可能在下载开始时询问保存位置，下载完成后在选择的保存位置寻找即可。
  :::

  ::: info 如何解压压缩包
  - 找到你下载的压缩包文件，鼠标右键点击；
  - 在出现的右键菜单中点击"全部解压缩"；
  - 选择解压的文件保存位置（默认保存到相同目录下的新文件夹中），点击"提取"。
  :::

- **Linux 用户**：下载 `.deb` 安装包，双击或使用命令行安装
- **macOS 用户**：下载 `.dmg`，打开后将应用拖入"应用程序"文件夹

### 2. 启动程序

- **Windows**：双击桌面快捷方式或开始菜单中的 SecRandom
- **Linux**：从应用菜单启动，或执行安装后的可执行文件
- **macOS**：从启动台或应用程序文件夹启动

### 3. 首次使用

首次启动会进入**初始设置引导（OOBE）**，按步骤完成：

1. 欢迎页（含语言选择）
2. 阅读并确认可验证抽取须知
3. 阅读并确认隐私政策
4. 阅读并确认 GPLv3 许可
5. 基本设置（外观/主题等）
6. 名单管理（导入或创建点名/抽奖名单）
7. 增强功能（语音/音乐/联动等）
8. 完成引导

::: tip
详细引导步骤请参阅[软件引导流程](/doc/guide/software-guide)。
:::

## 验证安装

### 查看版本号
启动后可在**标题栏**看到当前版本号；也可以在**设置 → 关于**中查看详细版本信息。

### 崩溃恢复
v3 内置崩溃恢复机制。若程序异常崩溃，再次启动时会显示恢复页面或自动重启，并可在日志查看器中查看错误详情。如需反馈问题，请在软件内通过"反馈"功能提交，或前往 [GitHub Issues](https://github.com/SECTL/SecRandom/issues) 反馈。
