# 软件引导流程

欢迎使用 SecRandom！首次启动软件时，初始设置向导将帮助你完成必要的确认与基础配置。本指南将详细介绍引导流程的每个步骤。

::: tip 版本提示
本文档对应 **v3** 的初始设置流程。v3 处于 Alpha 阶段，引导流程细节可能随版本调整，请以实际界面为准。
:::

## 引导流程概览

软件引导包含以下 **8 个步骤**（欢迎页 + 7 个配置/确认页），按顺序完成即可完成软件的初始配置：

| 步骤 | 页面 | 内容 | 预计耗时 |
|------|------|------|----------|
| 1 | [欢迎页](#1-欢迎页) | 显示应用 Logo、标题与语言选择 | 10 秒 |
| 2 | [可验证抽取须知](#2-可验证抽取须知) | 了解可验证抽取的两种模式与边界 | 1 分钟 |
| 3 | [隐私政策](#3-隐私政策) | 阅读并确认隐私政策 | 1 分钟 |
| 4 | [GPLv3 许可](#4-gplv3-许可) | 阅读并确认开源许可协议 | 1 分钟 |
| 5 | [基本设置](#5-基本设置) | 外观、主题等基础配置 | 1 分钟 |
| 6 | [名单管理](#6-名单管理) | 导入或创建点名/抽奖名单 | 5 分钟 |
| 7 | [增强功能](#7-增强功能) | 语音、音乐、联动等可选功能 | 3 分钟 |
| 8 | [完成](#8-完成) | 完成引导，进入主界面 | 10 秒 |

::: tip 提示
完成整个引导流程大约需要 10-15 分钟。名单管理是可选步骤，你可以跳过稍后在设置中完成。
:::

## 1. 欢迎页

### 页面内容
- 显示 SecRandom 的 Logo 和标题
- 左下方提供**语言选择器**，切换后立即生效（无需重启）

### 操作步骤
1. 选择你偏好的语言（中文/English/日本語）
2. 点击 **"开始"** 按钮进入下一步

::: tip
语言切换会刷新界面文字并保留当前流程，不会退出引导。
:::

---

## 2. 可验证抽取须知

### 页面内容
本页默认折叠显示"关于可验证抽取"的说明，你需要展开阅读并确认：

**普通模式**
- 会记录候选池、权重、抽取规则、随机材料和结果
- 可在离线状态下完成本地抽取并保存可重放证明（`.srproof.json`）
- 联网时，新的抽取会提交给 fair.sectl.cn 独立重放和签名
- 签名可发现提交后的证明文件篡改

**正式公证模式**
- 会先将匿名候选池、权重和规则锁定到 fair.sectl.cn
- 由服务端生成随机材料、计算结果并保存不可变官方证明
- 网络波动、断网、服务不可用导致未取得服务端完结证明时，不会产生本地替代结果，也不会自动切换模式
- 可防止本地抽取代码、随机材料和结果文件在已锁定流程中被替换；仍不能证明现实名单本身完整真实，或候选池在提交前未被人为筛选

### 操作步骤
1. 展开并阅读可验证抽取说明
2. 勾选 **"我已阅读并理解上述限制"**
3. 点击 **"下一步"** 继续

::: warning 必须确认
必须勾选确认才能继续下一步。
:::

---

## 3. 隐私政策

### 页面内容
显示 SecRandom 隐私政策（版本 1），主要条款包括：

- **本地数据**：名单、奖品、历史和设置默认保存在本地
- **Sentry 遥测**：开启后可能上传崩溃、日志、追踪和性能分析数据（可关闭）
- **在线状态统计**：正常上报包含粗略位置信息，匿名上报仅计入在线人数
- **选择与变更**：以上隐私选项可在"设置 → 通用 → 隐私"中随时修改

### 操作步骤
1. 阅读隐私政策全文
2. 勾选 **"同意隐私政策"**
3. 点击 **"下一步"** 继续

---

## 4. GPLv3 许可

### 页面内容
显示 GNU GPLv3 许可说明：

- SecRandom 以 GPLv3 许可发布
- GPLv3 允许运行、研究、修改和再分发软件
- 分发修改版本时需遵守 copyleft 条款，提供对应源代码并以 GPLv3 许可分发

### 操作步骤
1. 阅读 GPLv3 说明
2. 勾选 **"同意 GPLv3 许可"**
3. 点击 **"下一步"** 继续

::: tip
隐私政策或 GPL 版本更新时，软件会再次打开对应的确认页要求重新确认。
:::

---

## 5. 基本设置

### 页面内容
配置软件的基础外观与行为，包括：
- **主题模式**：浅色 / 深色 / 跟随系统
- **主题颜色**：选择界面主题色彩
- **字体**：界面字体家族与粗细（默认 MiSans）
- **开机自启**：是否随系统启动自动运行（可选）
- **崩溃恢复**：选择程序崩溃后的恢复方式

### 操作步骤
1. 根据需要调整外观选项
2. 点击 **"下一步"** 继续

::: tip
这些设置之后都可以在 **设置 → 通用 → 基本** 与 **设置 → 个性化 → 外观** 中修改。
:::

---

## 6. 名单管理

### 页面内容
建立首个可用名单，支持：
- **点名名单**：导入或创建学生名单（支持 `.xlsx`、`.xls`、`.csv`）
- **抽奖奖池**：导入或创建奖品池（可选）

### 操作步骤
1. 点击 **"导入"** 选择名单文件（Excel/CSV）
2. 在导入界面设置**列映射**（序号/编号、名称、性别、分组、标签）
3. 在预览区域确认数据无误
4. 点击 **"导入"** 完成

::: warning 注意
- 至少选择序号/编号列或名称列
- 两项均为空的行不会导入
- 重复名称可以选择"保留重名导入"或"自动重命名"，系统会用内部标识区分记录
:::

::: tip
名单管理是可选步骤。跳过的话，之后可以在 **设置 → 名单管理** 中随时创建与导入。
:::

---

## 7. 增强功能

### 页面内容
配置可选的增强功能，包括：
- **语音播报**：选择语音引擎（系统语音 / Edge TTS）与音色
- **音乐库**：导入抽取背景音乐（MP3/WAV/FLAC）
- **课程联动**：连接 CSES 课程表或 ClassIsland（可选）
- **抽奖开关**：是否启用抽奖功能

### 操作步骤
1. 按需配置语音、音乐等选项
2. 点击 **"下一步"** 继续

::: tip
这些功能之后都可以在 **设置 → 提醒设置**、**设置 → 个性化 → 音乐** 与 **设置 → 联动设置** 中修改。
:::

---

## 8. 完成

### 页面内容
- 显示引导完成提示
- 提供相关链接（官方文档、QQ 群、问题反馈等）

### 操作步骤
1. 点击 **"完成"** 按钮
2. 软件自动打开**主窗口**，开始使用

::: tip
引导完成后，软件进入正常启动流程并打开主界面。以后可在 **设置 → 关于** 中查看版本与支持信息。
:::

## 常见问题

### 引导过程中可以跳过隐私政策确认吗？
不可以。隐私政策、GPLv3 与可验证抽取须知都需要明确确认后才能继续，这是首次使用的必要步骤。

### 引导完成后还能修改语言吗？
可以。在 **设置 → 通用 → 基本 → 显示语言** 中修改（部分版本需要重启软件生效）。

### 引导时导入名单出错怎么办？
检查文件格式（支持 `.xlsx`、`.xls`、`.csv`，第一行作为列名），确认列映射正确。也可跳过导入，稍后在 **设置 → 名单管理** 中处理。
