# 界面介绍

::: tip 版本提示
本文档对应 **v3** 界面。v3 基于 C#/.NET 与 Avalonia + FluentAvalonia 构建，界面细节可能随版本调整，请以实际界面为准。
:::

## 界面概览

SecRandom v3 采用 Microsoft Fluent Design 设计语言，基于 **Avalonia + FluentAvalonia** 框架构建现代化跨平台用户界面。主窗口使用 FluentAvalonia 的 `NavigationView` 提供流畅的导航体验和一致的视觉风格。界面支持窗口大小记忆、自动居中、最大化状态保存等功能，确保用户获得舒适的使用体验。

## 主题与个性化

### 主题模式
- **浅色**：适用于明亮环境，提供清晰明快的视觉体验
- **深色**：适用于暗光环境，减少眼部疲劳
- **跟随系统**：自动根据系统主题切换

### 主题颜色自定义
- 支持自定义主题色（跟随系统或自定义）
- 主题色应用于按钮、进度条等界面元素，实现个性化外观

### 字体个性化
- 默认字体为 **MiSans**
- 支持多种字重选择（极细/特细/细体/常规/中等/半粗/粗体/特粗/极粗）
- 可实时预览字体显示效果（中文、英文、数字与符号样例）

::: tip
以上设置位于 **设置 → 个性化 → 外观**。
:::

## 主界面功能导航

### 点名页面
- 功能：随机点名、点名历史记录、点名设置
- 支持按名单范围、分组、性别与人数抽取
- 支持通过 URL 协议和 IPC 调用快速跳转

### 抽奖页面
- 功能：抽奖抽取、奖品管理、抽奖历史
- 支持奖盘/库存抽取、权重设置、公平抽取算法
- 可查看剩余名单（剩余奖项）

### 历史记录页面
- 功能：查看点名和抽奖历史记录
- 支持按名单/奖池筛选、全部记录/按时间查看
- 显示抽取方式（随机/公平）、点名数量、课程/课间等信息

### 闪抽（Quick Draw）
- 通过独立悬浮窗快速抽取学生
- 课堂中无需切换窗口，一键完成抽取

### 悬浮窗
- 主悬浮窗：提供点名/闪抽/抽奖入口，可自定义控件
- 支持贴边收纳、无焦点模式、前台窗口自动隐藏、长按操作

### 设置页面
- 功能：全局设置管理
- 按 v3 分组：通用（基本/安全/备份/隐私）、个性化（外观/浮窗/音乐）、名单管理、抽取设置、提醒设置（语音与音乐/通知）、历史记录、联动设置、可验证抽取、更多设置

## 系统托盘菜单

### 快速操作面板
- 显示/隐藏主窗口：快速切换主窗口显示状态
- 显示/隐藏悬浮窗：控制悬浮窗的显示
- 打开设置：快速访问设置页面
- 关于 SecRandom：显示应用信息

### 应用控制
- 重启应用：快速重启程序
- 退出应用：安全退出程序

## 其他界面特性

### 标题栏版本号
主窗口标题栏显示当前版本号，便于清楚知道当前版本。

### 关于页面
- 显示应用图标、名称与版本信息
- Banner 横幅展示
- 开源许可、支持与感谢信息

### 崩溃恢复界面
程序崩溃后再次启动时，显示恢复页面（含报错信息），可选择自动重启或查看日志。

### 移动端界面
Android/iOS 移动端使用原生 Avalonia 控件与 FluentAvalonia 设置项，底部导航栏提供点名/抽奖/历史等入口。
