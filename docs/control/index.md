# 集控概览

> **集控**是 SecRandom 的集中管理端：面向「一校多机、多教室」的部署，用一套 Web 界面统一查看设备状态、下发抽取策略与名单、执行远程操作，而不必逐台走到机器前。

::: tip 版本提示
集控随 **SecRandom v3** 提供，功能仍在持续完善中，界面与文案可能随版本调整，请以实际界面为准。
:::

## 它由三部分组成

| 部分 | 说明 |
|---|---|
| **设备端（被集控端）** | 教室机上安装的 SecRandom **桌面客户端**。它主动连出、上报自身状态，同时**保留本机开关**，随时可以拒绝被远控 |
| **Web 控制台** | 你在办公室用浏览器打开的界面：[secrandom-control.sectl.cn](https://secrandom-control.sectl.cn) |
| **集控服务** | 官方托管的服务端，负责账号、组、命令下发与审计 |

集控**不改变** SecRandom 的单机用法：不接入集控时，软件的一切功能照常可用；接入集控只是额外多了一层「可以被远程管理，也随时可以退出」的能力。

## 能做什么

- **看得到**：每台教室机是否在线、设备名、平台与版本、最后心跳、能力清单
- **管得住**：按「组」划分权限边界，邀请同事加入并分配角色
- **控得动**：禁止 / 允许抽取、立即抽取、播报一句话、远程修改设备设置、下发点名名单与奖池
- **查得清**：审计日志记录「谁、在哪台设备上、什么时候、做了什么、结果如何」

## 账号：用思拓创联账号登录

集控**没有独立的账号体系**：使用**思拓创联（SECTL）账号**登录即可，不需要另外注册，控制台也不会在浏览器里保存任何令牌。

## 一条原则：远程说了不算，设备说了算

每台教室机都保留自己的「允许被远程控制」开关。关掉之后，**无论服务端下发什么都不会执行**；即使账号被盗、或管理员误操作，也不等于教室机被控制。详见[安全与隐私](/control/security)。

## 开源与反馈

- **服务端与 Web 控制台目前尚未开源**。公开仓库 [SECTL/SecRandom-Control-Console](https://github.com/SECTL/SecRandom-Control-Console) 目前包含许可、信任边界与接入说明；后续条件允许时，官方会在该仓库补齐控制台源码与协议规范。
- **设备端的集控实现随客户端一同公开**（[SECTL/SecRandom](https://github.com/SECTL/SecRandom)，GPL-3.0）。
- 目前只有**官方托管**的集控服务，官方尚未提供自建服务端的方式。

::: warning 使用前请知悉
集控服务端由官方托管且当前未开源，因此你在使用时应把它当作「可能被攻破的组件」来对待：真正的安全边界在本机开关与组内角色上。这也是官方把「设备可否决一切远程操作」列为核心设计前提的原因。
:::
