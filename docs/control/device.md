# 设备端设置

> 位置：**设置 → 通用 → 集控**（页面标题「集控」）。这一页**只有桌面端有**：手机端不能作为被集控的设备。

## 页面上一共七项

| 设置项 | 官方说明 | 可改 |
|---|---|---|
| **允许被远程控制** | 这是本机自己的开关，关闭后无论服务端下发什么命令都不会执行 | 是 |
| **所属组 ID** | 由控制台建组后提供 | 是（**必填**） |
| **节点通道地址** | 默认使用线上节点通道；仅回环地址允许明文 `ws` 连接 | 是（一般不用动） |
| **节点 ID** | 安装时生成并长期保持不变，注册节点时把它填进控制台 | **只读** |
| **显示名称** | 控制台节点列表里显示的名字；留空则上报本机主机名 | 是（最长 64 字符） |
| **连接状态** | 断线后按退避自动重连；重试也没有意义的失败会停在这里等待修正 | 只读（旁边有**立即重连**） |
| **抽取锁定** | 由控制台设置；锁定后本机不再允许抽取 | 只读 |

::: tip 改完立即生效
这一页**没有「保存」按钮**：每次改动立刻落盘。地址填错时会提示「节点通道地址无效，未保存」，非法地址不会被写进配置。
:::

## 连接状态的含义

| 状态 | 含义 |
|---|---|
| **已关闭** | 本机开关关着，不会建立连接 |
| **等待登录或填写组 ID** | 还没登录思拓创联账号，或组 ID 还空着 |
| **连接中** | 正在建立长连接 |
| **已连接** | 已和集控服务握手成功，控制台可以看到这台设备 |
| **等待重连** | 断开后正在按退避自动重连（间隔逐渐拉长到一分钟左右） |
| **已停止重试** | 出现了**重试也没有意义**的失败，停在这里等你修正，修正后点**立即重连** |

「已停止重试」旁边的说明文字会告诉你具体原因：

| 说明 | 原因 | 处理 |
|---|---|---|
| 尚未登录 SECTL 账号 | 这台机器还未登录 | 在设置页登录 |
| 还没有填写所属组 ID | 组 ID 为空 | 从控制台复制组 ID 填入 |
| 组不存在，或当前账号不是该组成员 | 登录的账号不在该组里 | 用组内邀请码把该账号加入，或换成组内账号登录 |
| 该组下没有这个节点，请先在控制台注册 | 服务端关闭了「连接即登记」 | 请管理员在控制台登记这台设备的节点 ID |
| 请求格式错误，这是客户端问题 | 客户端与服务端协议不匹配 | 升级客户端，或反馈给官方 |
| 服务端拒绝了本机节点凭据… | 服务端未允许本平台接入 | 联系官方处理 |
| 节点通道地址无效 | 地址被改坏了 | 恢复为默认地址 |

::: warning 「凭据被拒」会自动停止重试
如果节点凭据连续被拒多次，客户端会**停止重连**并停在「已停止重试」，等你重新登录后再试——这是为了避免一个连不上的机器无限刷服务端。此时「立即重连」是唤醒它的按钮。
:::

## 「允许被远程控制」到底管什么

这是**这台机器自己的闸门**，也是整套集控里最重要的一道保护：

- **关掉后不建立连接**，控制台看不到它在线；
- **即使收到命令帧也不会执行**：命令被直接拒绝并回复「本机关闭了远控」；
- **服务端无法替你打开它**：控制台里没有任何接口能写入这个开关，它只由设备自己上报；
- **它也不住在普通设置文件里**：本机开关与已应用的锁定状态保存在 `data/config/control/node-state.json`，因此**导入设置或恢复备份都不会把远控悄悄打开**。

::: tip 关掉开关时，「抽取锁定」也随即失效
抽取锁定的闸门只在**本机允许被集控**时生效。所以：关掉开关 = 收回远控权，之前控制台下发的「禁止抽取」也不再约束本机。反过来，打开开关后，之前下发的锁定会重新生效。
:::

## 关于「抽取锁定」

- 它由控制台下发，是**期望状态**：设置好之后，即使设备离线也会在下次上线时生效；
- 锁定后**本机抽取与远程抽取都会被阻止**；
- 它是控制台的判断结果，与「本机已禁用远控」是两回事——后者是设备自己的开关，服务端改不了。

## 设备身份：节点 ID 与显示名称

- **节点 ID** 在首次运行时生成（一串随机字符），**长期不变**，重装才会变。它是这台机器在集控里的唯一标识；
- 控制台习惯把它当作详情页入口，**名字可以重复、重装会丢，只有节点 ID 能钉死一台机器**；
- **显示名称**由你在这台机器上填写（例如「301班讲台机」），留空则上报本机主机名。名字是设备自己的权威，控制台只在设备从未连过时提供一个初值；
- 出于审计会长期留存，建议**不要在节点 ID 或显示名里放隐私信息**。

## 网络与重连

- 设备是**主动连出**的：教室机在 NAT 之后也能接入，一般不需要在校园网上开放入站端口；
- 断线后按 1 秒 → 2 秒 → 4 秒……逐步退避重连，最长间隔约一分钟，握手成功后重置；
- 心跳约 25 秒一次；服务端超过约 75 秒收不到心跳就判为离线，控制台也会相应显示离线；
- **退出登录会立刻断开连接**，重新登录后重新连。

## 手机端：它是遥控器，不是被控设备

手机端**没有**「集控」设置页，也不会上报成节点。它的角色是**控制台侧**：

- 在手机 SecRandom 上登录同一账号，进入**抽取 → 远程抽取**；
- 选择分组与设备（会显示在线 / 离线）、读取名单、选择条件与人数，然后点**抽取**；
- **抽取实际发生在教室机那台设备上**，结果回传显示在手机上；设备的锁定、名单与本机策略全部照旧生效；
- 权限门槛与网页控制台一致：读名单需要管理员及以上，下发抽取需要操作者及以上；
- 手机端常见提示：设备离线时「命令会在它上线后补投」、超时「设备还没有回执，请稍后再看」、被拒「这台机器关闭了本机远控 / 这台机器的抽取被锁定 / 现在是上课时间，设备不允许抽取」。
