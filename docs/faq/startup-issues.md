# ::lucide:circle-help:: 程序无法启动

::: tip 版本提示
本文档适用于 **v3**（C#/.NET + Avalonia）。v3 处于 Alpha 阶段，如遇启动问题请优先尝试下方方案，并反馈至开发者。
:::

## **症状1**：修改设置后程序无法启动

**解决方案**：
- 1. 关闭程序（检查系统托盘或任务管理器确保完全退出）
- 2. 重置配置文件：在**安全模式/恢复页**中选择重置配置，或删除配置文件目录（`数据目录/config`）
- 3. 重新启动程序
- 4. 在设置中重新配置
- 5. 如果你确信这是一个 bug ，可将出现问题的配置文件反馈给开发者以便定位问题。

::: tip v2 用户
旧版（v2）的配置目录为 `程序目录/app/Settings`。v3 使用新的数据目录结构（名单、历史、证明、配置），旧版配置不会自动迁移，需重新配置。
:::

## **症状2**：程序卡在"注册 URL 协议"后闪退（v1.3.x 历史问题）

**解决方案**：
- 1. 如果是初次启动遇见此问题，先尝试重启电脑，查看 SecRandom 是否自启动。如果自启动成功，以后就不会出现此问题
- 2. 如未自启动（可能弹出 DLL 报错窗口），尝试 [点击此处](https://aka.ms/vc14/vc_redist.x64.exe) 下载并安装 VC 运行库
- 2. 重启电脑
- 3. 重新启动程序
- 4. 如仍存在问题，请反馈至开发者

::: warning v3 注意
v3 基于 .NET 10 构建，不再依赖 VC++ 运行库；如遇 URL 协议注册问题，请检查系统权限或杀毒软件拦截。
:::

## **症状3**：v3 启动时提示缺少 .NET 运行时

**解决方案**：
- v3 安装版通常**自包含**运行时，无需额外安装
- 若使用源码或精简便携版，请安装 [.NET 10 运行时](https://dotnet.microsoft.com/download)
- 检查系统架构（x64 / arm64）与安装包是否匹配

## **症状4**：v3 崩溃后无法正常启动

**解决方案**：
- v3 内置**崩溃恢复**功能：再次启动时会显示恢复页（含报错信息），可选择自动重启或查看日志
- 可在 **设置 → 通用 → 基本 → 崩溃恢复** 中选择恢复方式
- 通过 **日志查看器** 或日志目录查看崩溃原因，反馈给开发者
