# Backup Settings (General)

::: tip Version Notice
This document corresponds to the **v3** "Settings → General → Backup" page. v3 is in Alpha stage; settings may change with versions, please refer to the actual interface.
:::

> **Data peace of mind** - Protect your lists, history and configuration with automatic/manual backup and one-click restore.

## Automatic Backup

### Auto Backup
**Description**: Whether to enable automatic backup

- On: automatically creates backups at the set interval
- Off: no automatic backup (manual backup still available)

### Auto Backup Interval
**Description**: Set the automatic backup interval (days)

### Auto Backup Limit
**Description**: Set the maximum number of automatic backups to keep; 0 means unlimited

**Notes**: When the limit is exceeded, the oldest backups are cleaned up automatically

## Backup Contents

Choose which data to include in backup files:

| Content | Description |
|---------|-------------|
| **Config Files** | Software settings and configuration (config) |
| **List Data** | Roll call/lottery lists (list) |
| **History** | Draw history records (history) |
| **Draw Proof Files** | Proof files that reproduce and verify draw results (proofs) |
| **Audio Resources** | Audio resource files (audio) |
| **CSES Linkage** | CSES-related linkage data (CSES) |
| **Image Resources** | Member/prize image resources (images) |
| **Theme Resources** | Installed theme resources (theme) |
| **Run Logs** | Program run logs, may contain sensitive info (logs) |

::: warning Note
Backups never include passwords or security credentials. Security credentials are stored in a separate encrypted credential store and are not exported with backups.
:::

## Manual Operations

### Backup Now
Click the button to immediately create a full backup.

### View Backup Files
Open the backup folder and view the backup file list (filename, creation time, size).

### Restore Backup
1. Select the backup to restore in the list
2. Click **"Restore"**
3. Confirm to execute the restore

**Notes**:
- Restoring overwrites the corresponding current data
- A snapshot of current data is automatically created before restoring
- **Restart the app** for the restore to take effect
- Only backup files generated by SecRandom v3 are accepted

### Delete Backup
Select a backup and click **"Delete"**; this operation cannot be undone.

## Backup Usage

Shows the current size occupied by the backup folder for storage assessment.
