# Appearance Settings (Personalized)

::: tip Version Notice
This document corresponds to the **v3** "Settings → Personalized → Appearance" page. v3 is in Alpha stage; settings may change with versions, please refer to the actual interface.
:::

> **Personalized appearance** - Customize theme, font and accent color to make SecRandom match your taste.

## Theme

### Theme Mode
**Description**: Choose the interface theme style

| Option | Description |
|--------|-------------|
| **Light** | Light theme, suitable for daytime use |
| **Dark** | Dark theme, suitable for night use |
| **Follow System** | Automatically switches with the system theme |

### Theme Color
**Description**: Set the interface accent color

| Option | Description |
|--------|-------------|
| **Follow System** | Use the system accent color |
| **Custom** | Choose a custom accent color |

**Notes**: The accent color applies to buttons, progress bars, selected states and other UI elements

## Font

### Font Family
**Description**: Set the interface display font family

- Default font: **MiSans** (built-in)
- Other system fonts can be selected

### Font Weight
**Description**: Set the interface font weight

Options: ExtraLight, Thin, Light, Regular, Medium, SemiBold, Bold, ExtraBold, Black

## Font Preview

The settings page provides a live font preview:
- Chinese sample: 树梢树枝树根根 亲山亲水有亲人
- Group sample: 第一分组 张三 第二分组 李四 第三分组 王五 第四分组 赵六
- English sample: the quick brown fox jumps over a lazy dog
- Numbers & symbols sample: 点名 闪抽 抽奖 人脸抽 1234567890 +-*/

::: tip
The preview updates in real time when adjusting font and weight, making it easy to compare display effects.
:::
